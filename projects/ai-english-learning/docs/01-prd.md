## 一、产品定位

**一句话定位**：你的24小时AI英语私教，基于大模型提供个性化学习路径、场景化口语陪练、智能单词记忆，让学英语像聊天一样简单。

**核心价值**：
- 🎯 **真正个性化**：不是固定课程，AI根据你的水平、目标、薄弱点定制学习内容
- 🗣️ **敢开口**：24小时AI陪练，不用约课不怕尴尬，从单词到自由对话循序渐进
- 🧠 **记得住**：结合艾宾浩斯遗忘曲线+AI语境记忆，不做无用功
- 📱 **随时学**：手机PC多端同步，碎片时间就能学

## 二、用户画像与场景

### 用户画像1：职场新人小明
- **年龄**：25岁，工作1-3年
- **痛点**：学校学的英语忘光了，工作需要看英文文档、和外国同事开会，不敢开口说
- **目标**：3个月内能进行日常工作对话，看懂英文邮件
- **使用场景**：通勤路上背单词，午休15分钟练口语，晚上学15分钟

### 用户画像2：大学生小红
- **年龄**：20岁，大二学生
- **痛点**：要考四六级/雅思，哑巴英语，听力口语差，背单词背了就忘
- **目标**：半年内考过雅思6.5，能日常交流
- **使用场景**：图书馆学习，宿舍练口语，考前刷题

### 用户画像3：零基础家长老王
- **年龄**：35岁，想陪孩子学英语
- **痛点**：自己零基础，发音不准不敢教孩子，报班太贵没时间
- **目标**：和孩子一起从零开始学，能进行简单日常对话
- **使用场景**：晚上陪孩子一起学，周末亲子时间

## 四、核心功能详细说明

### 4.1 AI水平定级测试

**功能描述**：新用户首次进入，通过10分钟左右的AI自适应测试，评估用户当前英语水平。

**用户流程**：
1. 新用户进入 → 只问两个问题：① 你学英语是为了什么？（职场/考试/日常/陪孩子）② 你现在大概什么水平？（零基础/入门/中级/高级）
2. 可选做5分钟快速测试（选择题：词汇+语法+阅读），也可以直接跳过
3. 直接进入首页开始学习，不搞复杂的注册和问卷

**验收标准**：
- [ ] 新用户30秒内进入学习界面，不需要填一堆信息
- [ ] 测试题目10道选择题以内，时长不超过5分钟
- [ ] 支持跳过所有引导，直接开始用
- [ ] 学习过程中AI会根据你的表现动态调整难度，不需要一开始就定死

---

### 4.2 智能单词记忆

**功能描述**：不是传统的单词表，AI根据用户水平、记忆曲线、学习目标智能安排单词学习和复习。

**核心逻辑**：
1. **单词推荐**：根据用户目标（职场/考试/日常）推荐对应词表
2. **记忆与掌握闭环**：查看答案或独立拼写失败只证明“当前未记住”，不能提升熟练度；系统先在当天后续题目中受控穿插，再按 D+1、D+3、D+7、D+14 的默认节奏安排无答案泄露的独立拼写。只有跨日连续满足掌握证据后才退出薄弱队列，之后在 D+30 做普通维护复习；具体规则见 4.2.2
3. **双模式自由切换**：
   - **📖 纯背单词模式**：不考试、不做题，就安安静静看单词
     - 显示单词、音标、中文意思
     - 给3个实用场景例句
     - 讲清楚这个单词怎么用、常见搭配、和同义词的区别
     - 认识就点"下一个"，不认识就点"再看看"，简单放松
   - **✏️ 填空练习模式**：主动回忆，记得牢
     - 给一个缺了单词的句子 + 中文意思
     - 句子缺词位置本身就是唯一答案入口；每个待填英文字母对应一个字母槽，页面不再提供句子下方的独立答案输入框
     - 初始空槽直接表达答案长度；例如目标词为 `apple` 时显示 `_____`，输入 `a` 后显示 `a____`，继续输入依次形成 `ap___`、`app__`、`appl_`、`apple`
     - 系统随机提示字母固定在对应位置，并与用户已输入字母合并为同一个答案；输入过程中不得重排提示或覆盖用户已输入内容
     - 用户键入字母时依次填入下一个未填写、非提示的字母槽；退格删除最近一个可编辑字母，也可定位到任一可编辑槽修改
     - 支持粘贴完整答案或剩余字母；完整答案按目标位置与既有提示合并，剩余字母按未填写槽位依次填入，固定分隔符不重复占位
     - 连字符、撇号、空格等分隔符按目标词原样固定显示，不作为可编辑字母；输入、退格和粘贴时自动跨过
     - 答案字母不区分大小写；本期不以大小写作为拼写题考点，非答案字符不得进入字母槽
     - **同义词兼容规则**：同义词仍可作为可接受答案，但只有字母数量、分隔符和当前提示字母均与本题槽位兼容的候选才能在本题判为正确；不兼容的同义词在答后扩展中展示，不得让用户在无法容纳它的固定槽位中作答
     - 用户提交时，未填完整则提示剩余字母数并回到首个未填槽，不判为错误；填完整后再判断答案
     - 答案错误时保留用户输入和系统提示，允许直接退格、定位并修改后重新提交，不自动跳题或用正确答案覆盖输入
     - 答案正确时给出明确反馈；用户通过“下一题”操作或键盘确认进入下一题，新题清空上一题输入并生成本题稳定的随机提示
     - 答题完成或主动查看答案后给出扩展：这个词的其他同义词、常见搭配、用在什么场景
     - 错了不打击；用户可继续修改重试，也可主动查看答案并结束本轮独立作答
4. **应用**：在口语对话中遇到刚学的单词，AI会主动用，帮你巩固

#### 4.2.1 “查看答案”产品规则

**目标**：让确实不会作答或希望核对的用户，主动结束本轮独立作答后，直接在现有句中行内字母槽看到完整正确答案；同时保证“看过答案”不会被计作独立答对或提高熟练度。

**1. 可用时机与触发条件**

- “查看答案”是填空练习中的 P0 次要操作。题目加载后，在未作答、部分作答、提交未完成和提交错误状态均可使用；不要求先提交，也不设置倒计时或自动揭晓。
- 用户已经独立答对时，正确答案已经完整呈现，“查看答案”不再可触发，也不得补记为看过答案；此时主操作保持为“下一题”。
- 首次触发只进入误触确认，明确告知“查看后本题不计为独立答对”；只有用户再次明确确认才揭晓。取消、按 `Esc` 或离开确认状态均不改变答案和记录。
- 同一题重复确认必须幂等：只产生一次揭晓记录，不重复结算进度、正确率或复习记录。

**2. 正确答案的直接展示方式**

- 确认查看后，系统用本题标准目标词完整替换现有句中行内字母槽内容；不得新增句子下方答案框、独立答案卡或要求用户跳转后才能看到答案。
- 分隔符、大小写规则与现有字母槽一致。存在可接受同义词时，揭晓当前槽位对应的标准目标词；其他同义词继续放在答后扩展，不切换槽位长度。
- 字母槽进入只读的“正确答案，已查看”状态，状态表达不得只依赖颜色。系统须保留揭晓前的空白、部分输入或错误输入快照，用于本题结果和复习记录，但不在槽中与正确答案混排。
- 揭晓前不得通过可见文案、可访问名称、复制内容或其他前端状态泄露完整答案。

**3. 各答题状态下的行为**

| 揭晓前状态 | 确认查看后的结果 | 结果分类 |
|---|---|---|
| 未作答 | 直接填入完整标准答案，槽位只读 | `revealed` |
| 部分作答 | 保存部分输入快照，再填入完整标准答案 | `revealed` |
| 已提交但未填完整 | 保留“不判错”的既有语义，保存输入快照后揭晓 | `revealed` |
| 已提交且答错 | 保存错误答案与提交结果，再揭晓 | `revealed` |
| 已提交且答对 | 不再触发查看答案，保持独立答对结果 | `independent-correct` |

**4. 揭晓后的编辑、重试、提交与下一题**

- 揭晓后，本轮独立作答结束：字母槽不可编辑，“提示”和“检查答案”不可使用，“下一题”立即可用。
- 用户可以选择“重新作答本题”。重试会清空可编辑字母，恢复本题最初的稳定提示字母，并重新允许编辑、提示和检查；不得生成另一套随机提示来降低或提高难度。
- 揭晓后的重试属于辅助练习。用户可以重新提交并获得对错反馈，但即使答对也只记为 `correct-after-reveal`，不得改写为独立答对、提高本题正确率或获得掌握度收益。
- 用户选择“下一题”后才把本题计入今日题量进度；仅打开确认但未确认，不得结算或推进本题。

**5. 计分、正确率、连续学习、进度与复习记录**

- 本题结果至少区分：`independent-correct`（揭晓前独立答对）、`revealed`（已查看答案）、`correct-after-reveal`（查看后重试答对）和作答中的错误/未完成状态。
- 正确率分子只计入揭晓前独立提交正确的题目。已确认揭晓且通过“下一题”结算的题目计入分母但不计入分子，避免通过查看答案抬高正确率；查看后重试答对也不回填分子。
- 确认揭晓会中断“连续答对”；不能把查看答案或查看后答对计入连对。
- 已揭晓题在进入下一题时可以完成今日题量进度，但必须标记为“已复习/未独立答对”，不得显示为完成一道正确题。
- “连续学习天数”沿用既有按学习日/会话完成的规则：单独点击查看答案不会新增学习天数；包含揭晓题的已完成学习会话仍可算作学习日，但不会产生正确率或熟练度收益。
- 复习记录须保存揭晓时间、揭晓前状态、揭晓前输入快照、标准答案、是否查看后重试及最终辅助练习结果。确认揭晓必须幂等登记为一次 `reveal` 薄弱证据；同一作答尝试重复查看不重复登记，新作答尝试再次查看则形成新的证据。查看答案不得提升熟练度或延长复习间隔，并按 4.2.2 进入当天穿插与跨日待复习队列。

**6. “提示”“检查答案”“查看答案”的关系**

- **提示**：只补充部分稳定字母，用户仍处于独立作答，可继续编辑和提交；提示使用情况可单独记录，但不直接结束本题。
- **检查答案**：校验当前完整输入；未填完整时只提示剩余字母数，不判错、不揭晓。
- **查看答案**：主动结束本轮独立作答并揭晓完整答案，必须经过一次明确确认；它不是更多提示，也不能由“检查答案”自动触发。
- 揭晓后，提示与检查答案保持不可用，直至用户主动选择“重新作答本题”。不得把双击、长按、全局回车或连续答错隐式解释为查看答案。

**7. 键盘、移动端与无障碍约束**

- “查看答案”必须可以通过顺序键盘焦点到达，并支持 `Enter` 或空格触发；确认状态支持 `Esc` 取消。不得绑定全局 `Enter` 直接揭晓答案。
- 移动端确认揭晓后收起软键盘，保证正确答案、结果状态和“下一题”仍在当前任务流内可访问；不要求用户横向滚动或重新打开键盘才能继续。
- 揭晓后将焦点移动到结果摘要，或以等效方式立即播报结果；字母槽组的可访问名称至少表达“正确答案、已查看”，并能按字符正确读出字母和固定分隔符。
- 未作答、部分作答、错误、正确、已查看和查看后答对均须有非颜色状态文本；确认提示、只读状态和下一步操作对屏幕阅读器可感知。

**8. 边界条件与不做项**

- 确认前切换学习模式、离开本题或取消确认，不产生查看记录；确认后离开或刷新时，已查看状态和复习记录不得回退成未查看。
- 1～2 个字母短词以及含空格、连字符、撇号的答案仍按完整标准答案揭晓，固定分隔符不参与编辑或计数。
- 本次不做倒计时自动揭晓、连续答错自动揭晓、看答案奖励积分或查看后恢复独立答对资格。v1.4 正式发布范围要求服务端保存并跨设备同步查看／答错证据与复习状态；仍不做自动学习或不透明的个性化预测算法。
- 本次只定义产品行为，不修改 `docs/03-ui-prompt.md`、`ui/`、前端代码、后端代码，也不替代 UI/UX 对视觉层级和组件形态的后续设计。

**用户流程**：
1. 打开APP → 点"背单词"
2. 顶部可以切换「纯背模式」或「填空模式」，默认先纯背后练习
3. 先处理逾期与今日到期复习，再学新单词；每题都能知道“为什么现在复习”
4. 填空题可继续作答、检查答案，或确认“查看答案”后直接在原字母槽看到完整答案；查看或答错会形成薄弱证据
5. 当天后续题目按上限随机穿插薄弱词；跨日按 S1～S4 进行无答案泄露的独立拼写检查
6. 用户可跳过、暂停或重置掌握进度；达到四个跨日掌握证据后退出薄弱队列，D+30 再做普通维护复习
7. 完成今天的量自动结束，不做积分惩罚或连续催促

**验收标准**：
- [ ] 支持不同目标词库（日常/四级/六级/雅思/职场）
- [ ] 每个单词至少3个实用例句，不是陈旧的教科书句子
- [ ] 双模式切换流畅，纯背模式简单放松，填空模式交互爽快
- [ ] 填空模式按可接受答案集合判定；槽位不兼容的同义词只用于答后扩展，不造成“语义正确但无法输入”的死路
- [ ] 填完不管对错都给扩展：同义词、搭配、用法，不是只说对错
- [ ] 句子下方不存在独立答案输入框，唯一答案入口位于句子缺词处；目标词 `apple` 输入 `a` 后显示 `a____`，连续输入可完成 `apple`
- [ ] 随机提示字母与用户输入稳定合并；继续提示或更换提示不得删除、移动或覆盖用户已输入字母
- [ ] 支持连续输入、退格、定位修改和粘贴；输入或粘贴完整答案及剩余字母均能按槽位正确合并
- [ ] 提交未完成答案时不判错，并告知剩余字母数；错误答案保留且可修改重交；正确答案可通过明确操作进入下一题
- [ ] 1 个字母的短词不直接提示答案；2 个字母的短词即使有提示也至少保留 1 个字母让用户填写，且输入、提交和修改流程完整
- [ ] 含连字符、撇号或空格的答案固定显示分隔符，输入、退格、粘贴和校验均只在字母槽上推进，不因分隔符错位
- [ ] 移动端点击句中槽位能调起可用的英文文本键盘；软键盘出现后仍可看见当前作答位置、修改答案并提交，自动更正不得静默改写答案
- [ ] 仅用键盘即可聚焦答案、输入、定位、退格、粘贴、提交和进入下一题；焦点顺序连续可预期
- [ ] 辅助技术将整组字母槽识别为一个有名称的答案输入，能获知句子上下文、答案字母数、已输入数量、提示位置、剩余数量及正确/错误结果；状态表达不只依赖颜色
- [ ] 查看答案或完整拼写错误能幂等形成薄弱证据，并按 4.2.2 完成日内穿插、跨日阶段、提醒、掌握退出与失败恢复
- [ ] 支持标记熟词、收藏单词
- [ ] 界面极简，没有多余按钮和广告

**“查看答案”专项验收标准（Given-When-Then）**：

- **AC-RA-01 可用状态**：Given 填空题处于未答、部分作答、提交未完成或提交错误状态，When 用户查看可用操作，Then “查看答案”可触发，且无需先答错或等待倒计时。
- **AC-RA-02 正确状态**：Given 用户已在揭晓前独立答对，When 正确结果出现，Then 不再允许触发“查看答案”，结果保持 `independent-correct`。
- **AC-RA-03 误触保护**：Given 用户首次触发“查看答案”，When 尚未明确确认，Then 系统说明查看后不计独立答对，且答案、进度、计分和复习记录均不改变。
- **AC-RA-04 取消确认**：Given 查看答案确认已打开，When 用户取消、按 `Esc`、切换模式或离开本题，Then 不揭晓答案、不写入查看记录，并恢复原作答状态。
- **AC-RA-05 直接揭晓**：Given 用户明确确认查看，When 揭晓完成，Then 当前句中原字母槽直接显示完整标准答案，不新增句下答案框或跳转页面。
- **AC-RA-06 输入快照**：Given 揭晓前存在空白、部分输入或错误答案，When 用户确认查看，Then 系统保存揭晓前状态和输入快照，并以标准答案替换槽内可见内容。
- **AC-RA-07 槽位只读**：Given 答案已揭晓，When 用户尝试输入、粘贴、退格或定位修改，Then 槽位保持只读，并以非颜色方式表达“正确答案，已查看”。
- **AC-RA-08 提示与检查**：Given 答案已揭晓且未进入重新作答，When 用户检查可用操作，Then “提示”和“检查答案”不可用，“下一题”立即可用。
- **AC-RA-09 重新作答**：Given 答案已揭晓，When 用户选择“重新作答本题”，Then 清空可编辑字母、恢复原稳定提示集并重新允许作答，不生成新的提示集。
- **AC-RA-10 查看后答对**：Given 用户查看答案后重新作答并提交正确，When 系统结算，Then 结果为 `correct-after-reveal`，提供练习反馈但不计独立答对、正确率分子或熟练度收益。
- **AC-RA-11 正确率**：Given 已查看题通过“下一题”结算，When 更新正确率，Then 本题计入分母、不计入分子；仅揭晓前独立答对计入分子。
- **AC-RA-12 连续与进度**：Given 用户确认查看答案，When 结算本题，Then 连续答对被中断；进入下一题时今日题量可推进，但状态标记为“已复习/未独立答对”。
- **AC-RA-13 连续学习天数**：Given 用户仅确认查看答案但未完成既有学习日/会话条件，When 更新连续学习天数，Then 不新增学习天数；会话正常完成时可计学习日，但揭晓题不产生答对收益。
- **AC-RA-14 复习语义**：Given 本题被确认揭晓，When 写入复习记录和安排下次复习，Then 保存揭晓时间、前态、输入快照、标准答案、重试与最终结果，且复习不得晚于答错基线。
- **AC-RA-15 幂等性**：Given 同一题已成功揭晓，When 用户重复点击、双击或重复确认，Then 只保留一次揭晓与结算记录，不重复推进进度或改变统计。
- **AC-RA-16 键盘操作**：Given 用户仅使用键盘，When 依次聚焦并操作查看答案，Then 可用 `Enter`/空格触发、`Esc` 取消，且全局 `Enter` 不会直接揭晓。
- **AC-RA-17 移动端**：Given 移动端软键盘处于打开状态，When 用户确认查看，Then 软键盘收起，正确答案、状态和“下一题”仍可访问和操作。
- **AC-RA-18 无障碍播报**：Given 辅助技术正在读取页面，When 答案揭晓，Then 用户能立即获知“正确答案、已查看”、完整字母与分隔符、结果状态和下一步操作，且信息不只依赖颜色。
- **AC-RA-19 防答案泄露**：Given 用户尚未确认查看且未独立答对，When 使用可见内容、复制或辅助技术访问题目，Then 不得提前获得完整标准答案。
- **AC-RA-20 特殊答案**：Given 目标词为短词或含空格、连字符、撇号，When 用户确认查看，Then 完整标准答案按原结构显示，固定分隔符正确保留且不被计为可编辑字母。

#### 4.2.2 薄弱词、日内穿插与跨日记忆闭环

**目标**：把“我不会”变成可追溯的学习证据，并通过当天受控复现和跨日独立拼写，持续安排该词，直到用户在没有答案泄露性辅助的前提下多次跨日拼写正确。

**产品承诺边界**：本规则能把“记住”定义为可验收的行为结果，不能保证用户永久不忘。产品统一使用“达到当前掌握标准”，不得宣传为永久记忆或医学意义上的记忆保证。

##### 1. 术语与结果分类

| 术语 | 产品定义 | 是否推进掌握 |
|---|---|---|
| 薄弱证据 | 同一次作答中确认查看答案，或完整提交后拼写错误 | 否；触发或重置复习闭环 |
| 掌握合格尝试 | 从无答案字母的初始状态独立作答；本次尝试未查看答案、未使用提示字母、未看到可泄露答案的辅助；完整拼写为可接受答案 | 是，记为 `clean-independent-correct` |
| 辅助尝试 | 使用了提示字母、查看答案、查看后重试，或其他会泄露完整/部分答案的辅助 | 否；即使答对也只记 `assisted-correct` 或 `correct-after-reveal` |
| 同日加固 | 薄弱证据产生后，在同一学习日的后续题目中再次出现该词 | 只用于练习，不计跨日掌握次数 |
| 跨日阶段 | D+1、D+3、D+7、D+14 四个默认复习检查点 | 每个阶段最多贡献一次掌握合格证据 |
| 学习日 | 按用户确认的学习时区，从当地 00:00 到 23:59 计算 | 防止通过改时钟或同日重复刷题伪造跨日证据 |
| 学习项 | 词形、目标含义与题目身份的组合；同形异义词可为不同学习项 | 去重按学习项身份，不只按单词文本 |

补充规则：

- 未填完整时点击“检查答案”仍不判错，不产生薄弱证据；打开但取消“查看答案”确认也不产生证据。
- 同一作答尝试确认查看后，无论重复点击、刷新或返回，只登记一条 `reveal` 薄弱证据；之后的新作答尝试再次查看，可以登记新的证据。
- 使用系统随机提示字母后答对，仍可获得普通练习反馈，但不能叫“真正独立拼写”，不能推进掌握阶段。
- 一个学习项在同一学习日最多贡献一次跨日掌握合格证据；当天先看过答案或使用过泄露性辅助后，该学习项当天后续答对均只算加固，最快从下一学习日重新取得掌握资格。

##### 2. 当天随机穿插

触发与次数：

1. 新增薄弱证据后，学习项进入 `same-day-pending`。
2. 当天最多额外穿插该学习项 2 次；同一作答尝试的重复查看不会增加穿插次数。
3. 第 1 次穿插随机落在薄弱证据之后第 3～7 道“其他学习项已结算题”之间。
4. 第 2 次穿插在第 1 次穿插结算后，再随机落在第 3～7 道其他学习项之间；无论第 1 次答对、答错或再次查看，都不得紧邻重复。
5. “随机”只在上述合格窗口内改变具体位置，不能突破次数、间隔、会话上限或优先级；同一会话恢复后不得反复重排已确定的插入位置。

去重与题量上限：

- 同一学习项两次出现之间至少隔 3 道其他学习项；相同学习项不得连续出现。
- 一次会话的日内额外穿插总量取“8 道”与“本次会话原计划题量的 30%（向上取整）”中的较小值。
- 日内穿插只增加练习题，不改变用户原计划新词数量；达到上限后，其余待穿插项保留为待处理，不得悄悄丢弃。
- 当剩余题量不足以满足至少 3 道间隔时，不强行追加或紧邻插入：优先等待当天下一次会话；当天不再学习则直接保留 D+1 跨日复习。
- 同一个学习项在队列中只能有一个当前穿插位置；重复证据提高其复习原因强度，但不能复制成多条相邻题。

多薄弱词竞争：

1. 先保证所有已进入合格窗口的薄弱词各获得一轮机会，再给任何单词第 2 次机会。
2. 同一轮内依次比较：窗口最接近关闭者 → 当天薄弱证据更多者 → 距离上次出现更久者 → 在合格项中随机打散。
3. 已到期/逾期的跨日复习优先于日内穿插；日内穿插优先于普通新词，但不得突破会话额外题量上限。
4. 被“暂停”的学习项不参与竞争；被“跳过”的学习项按 4.2.2 第 8 节处理，不得立刻再次插到下一题。

##### 3. 跨日默认记忆曲线

以最近一次薄弱证据所在学习日为 D0。用户按时完成且每次都是掌握合格尝试时，默认节奏为：

| 阶段 | 默认到期日 | 合格结果 | 不合格结果 |
|---|---|---|---|
| S0 当日加固 | D0，当天最多 2 次 | 只记录加固完成，不计跨日掌握 | 答错/查看追加证据，但当日仍受次数与题量上限约束 |
| S1 次日回忆 | D+1 | 进入 S2 | 答错/查看重置为 S0；辅助答对停留 S1 |
| S2 短期间隔 | D+3 | 进入 S3 | 答错/查看重置为 S0；辅助答对停留 S2 |
| S3 周期检查 | D+7 | 进入 S4 | 答错/查看重置为 S0；辅助答对停留 S3 |
| S4 掌握检查 | D+14 | 达到当前掌握标准并退出薄弱队列 | 答错/查看重置为 S0；辅助答对停留 S4 |
| M1 维护复习 | D+30 | 保持 `mastered`，回到普通复习节奏 | 答错/查看重新进入 S0 薄弱闭环 |

调度解释：

- 表中 D+1、D+3、D+7、D+14、D+30 是按时完成时的标称节奏；实际下一间隔依次为完成后的 1、2、4、7、16 个学习日。
- 用户漏学时，当前阶段保留为 `overdue`，下一次打开先做这一阶段；不会把错过的多个阶段压缩到同一天连续补完。
- 逾期后合格完成，下一阶段从实际完成日重新计算，避免同日追赶多个检查点。
- 任一跨日阶段答错或确认查看答案，掌握进度重置，保留全部历史证据；若当天还有容量可进入日内穿插，跨日从下一学习日 S1 重新开始。
- 任一阶段使用提示字母或其他答案泄露性辅助后答对，不推进阶段；该阶段顺延到下一学习日，不用同日重复答对洗成掌握证据。

##### 4. “记住 / 能独立拼写”的判定

一个学习项只有同时满足以下条件，才从薄弱队列退出并标记为 `mastered`：

1. 在 S1、S2、S3、S4 各取得 1 次 `clean-independent-correct`，共 4 次；
2. 4 次发生在 4 个不同学习日；
3. S4 成功不得早于最近一次薄弱证据后的第 14 个学习日；
4. 每次都从无答案字母状态开始，未查看答案、未使用提示字母、未接受会泄露答案的辅助；
5. 每次完整拼写命中当前题目的可接受答案集合；大小写与固定分隔符仍沿用既有规则。

同日穿插答对、看答案后重试答对、带提示答对和纯背模式“认识”都不能替代以上任一跨日证据。达到标准后退出“薄弱词”队列，但在 D+30 进入普通维护复习；以后任何独立拼写错误或确认查看都会立即恢复薄弱状态并重新从 S0 开始。

##### 5. 应用内待复习队列与提醒

“每天定时推出来”的 MVP 产品语义是：

- 每个学习日应用内生成一个可进入的“待复习”队列，明确显示到期数量、逾期数量和每个学习项的复习原因；它不等于系统能在未授权时强制弹出或自动打开页面。
- 默认提醒时间为用户学习时区的 20:00，用户可以修改时间、关闭提醒或设置免打扰时段；默认免打扰为 22:00～次日 08:00。
- 每个学习日最多发送 1 次外部复习提醒。提醒时间落入免打扰时段时，顺延到免打扰结束；用户当天已完成所有到期项时不再提醒。
- 外部通知只在用户主动开启且系统权限允许时发送。未授权、被拒绝或平台不支持时，只保留应用内待复习状态，并明确说明“通知未开启/不可用”；不得记录为已送达。
- 用户在提醒时间后才打开应用时，直接看到真实待复习队列；不补发多条过期提醒，不用连续弹窗追赶。
- 用户可以暂停全部复习提醒，但暂停提醒不等于清空到期任务；再次开启时继续展示真实逾期项。

离线与跨时区：

- MVP 不支持离线完成和写入复习结果。离线时不得把题目算完成、答对或已掌握；到期项保持到期/逾期，恢复可用连接后继续。
- 离线期间无法确认的外部提醒不得伪记为已送达；恢复连接后只显示当前队列，不补发当天重复提醒。
- 首次开启提醒时，以用户确认的学习时区为准，默认建议当前设备时区。检测到设备时区变化时先让用户选择“继续原学习时区”或“切换到当前时区”，未确认前不得静默重排历史学习日。
- 切换学习时区只重算未来到期时刻和提醒时刻，不改写既有证据的原始时间、当时学习日或掌握结论；同一自然行程日不得因跨时区收到重复提醒或贡献两次跨日掌握证据。

##### 6. 队列优先级与每日上限

单词学习会话的默认优先级为：

1. 逾期跨日复习；
2. 今日到期跨日复习；
3. 已进入合格窗口的日内薄弱词穿插；
4. 普通新词与其他计划题。

同一优先级内按“到期更早 → 最近薄弱证据更多 → 距离上次出现更久 → 合格项随机打散”排序。跨日待复习队列默认每日展示上限为 20 个学习项；超过 20 个时，剩余项继续清楚显示为逾期，用户可以主动“继续复习”，但系统不得把未展示部分标为完成或自动延后成未到期。

##### 7. 计分、连续学习、掌握度与历史

- 既有题目正确率继续遵守 4.2.1：`revealed` 和 `correct-after-reveal` 不计正确率分子；已结算查看题计入分母。
- 新增“独立拼写正确率”：分子只计 `clean-independent-correct`；分母计已结算的无辅助正确、答错、`revealed`、`assisted-correct` 和 `correct-after-reveal`。未完成、跳过、暂停和数据异常不进入分子或分母。
- 同一尝试只能有一个最终计分结果；重复查看、重复提交、刷新或重放不得重复累计。
- 确认查看或答错会中断连续答对；辅助答对不恢复连续答对。连续学习天数仍按完成既有学习日/会话条件计算，单独查看答案、打开队列或收到提醒不能新增学习天数。
- 掌握度使用可解释阶段而非虚假精确百分比：`薄弱待加固` → `S1` → `S2` → `S3` → `S4` → `已掌握`；失败后显示“因本次答错/查看答案，已重新开始巩固”。
- 历史至少保留：学习项、证据类型、作答尝试、原始时间与学习时区、揭晓前输入快照、是否使用提示/答案、最终结果、前后阶段、到期日、跳过/暂停/重置原因。
- 每次进入复习题都要有可理解的原因，例如“昨天查看过答案”“3 天前拼写错误”“S3 周期检查到期”“逾期 2 天”；不得只显示不可解释的算法分数。
- v1.3 之前无法确认是否使用提示的历史答对记录，不追认成掌握合格证据；可保留为普通练习历史。

##### 8. 暂停、跳过与重置

- **跳过本题**：当天第一次跳过时移到当前队列末尾，不计对错、不推进阶段；同一学习项当天第 2 次跳过则顺延到下一学习日并保留逾期/到期原因，不再当天反复出现。
- **暂停学习项**：用户可选择暂停 1、3、7 或 30 个学习日。暂停期间不进入题目队列、不触发该词提醒、不改变掌握阶段；到期后按暂停前阶段恢复，历史保留。
- **重置掌握进度**：必须明确确认。重置后阶段回到 S0、下一学习日进入 S1；既有证据只标记为“重置前历史”，不得被删除或改写。
- **暂停全部提醒**：只关闭提醒，不暂停单词本身的到期时间；待复习数与逾期状态继续真实累计。

##### 9. 状态机

| 当前状态 | 触发 | 下一状态 | 关键副作用 |
|---|---|---|---|
| `ordinary` | 确认查看或完整提交错误 | `weak-captured` | 幂等写入薄弱证据，掌握收益为 0 |
| `weak-captured` | 队列重新计算 | `same-day-pending` | 生成最多 2 次受控穿插窗口与 S1 到期日 |
| `same-day-pending` | 日内练习完成或当天容量耗尽 | `cross-day-waiting-S1` | 当日结果只作加固，等待下一学习日 |
| `cross-day-waiting-Sn` | 到期 | `review-due-Sn` | 进入到期/逾期队列并提供原因 |
| `review-due-Sn` | 开始作答 | `reviewing-Sn` | 锁定本次尝试的提示暴露与结果语义 |
| `reviewing-Sn` | 掌握合格答对 | 下一阶段等待；S4 后为 `mastered` | 同一学习日最多推进 1 个阶段 |
| `reviewing-Sn` | 辅助答对 | 原阶段等待 | 不推进，顺延到下一学习日 |
| `reviewing-Sn` | 答错或确认查看 | `weak-captured` | 重置阶段，保留历史，可进入当日加固 |
| 任一活动状态 | 暂停学习项 | `paused` | 保存原阶段和恢复日，不参与队列 |
| `paused` | 暂停到期/用户提前恢复 | 暂停前状态 | 不补造暂停期内的多次复习 |
| `mastered` | D+30 维护到期 | `maintenance-due` | 作为普通维护复习，不显示为薄弱词 |
| `mastered` / `maintenance-due` | 答错或确认查看 | `weak-captured` | 恢复薄弱队列并从 S0 重启 |
| 任一状态 | 题库或记录异常 | `data-exception` | 不计分、不推进，保留可追溯原因 |

状态优先级：`data-exception` 与 `paused` 覆盖普通队列展示；`reviewing` 只代表当前尝试；其余持久状态中，以最近有效薄弱证据和最高未完成阶段为准，不能同时把同一学习项显示成“已掌握”和“薄弱”。

##### 10. 异常与边界

- **重复记录**：同一学习项、同一作答尝试、同一事件类型只保留一次业务效果；重复事件可以留审计痕迹，但不能重复计分、插题或重置阶段。
- **多端/刷新竞争**：v1.4 正式发布以服务端学习证据为准；同一页面刷新或多端恢复时必须幂等合并已结算结果，不重新获得掌握资格、不丢失查看／答错证据，也不重复提醒。
- **题库缺失**：目标答案、含义或题目身份缺失时不出题、不计错、不降低掌握度，标记 `data-exception` 并继续下一可用题；修复后恢复原阶段。
- **同形异义词**：按学习项身份分别调度；只有产品明确认定为同一学习项时才合并，不能仅因拼写相同误合并。
- **非法到期时间**：若到期时间早于最新证据或无法解析，保守地生成一个“记录异常，待复习”的当前任务，只出现一次、不追补多个阶段，并保留异常原因。
- **大量逾期**：只按每日上限逐步呈现，剩余项保持可见逾期；不一次性轰炸提醒，不把逾期伪装成已延期完成。
- **空队列**：明确说明“今天没有到期复习”，并允许进入普通学习；不得生成虚假复习任务维持活跃度。
- **短词与分隔符**：掌握合格尝试仍需从无答案字母状态独立完成；固定连字符、空格、撇号不算答案泄露，系统提示字母算泄露性辅助。

##### 11. v1.3 记忆闭环基线与 v1.4 发布增量

**P0 包含**：查看/答错薄弱证据、日内最多 2 次受控穿插、固定 D+1/D+3/D+7/D+14 掌握路径、D+30 维护、待复习/逾期队列、可设提醒时间与权限/免打扰语义、独立拼写正确率、阶段式掌握度、原因与历史、跳过/暂停/重置、离线/时区/数据异常边界。

**本次不做**：个性化机器学习调度、根据情绪或设备自动改变间隔、永久记忆保证、离线答题与离线结算、短信／邮件提醒、连续催促、社交排名、积分惩罚、技术架构、视觉设计或前后端实现。跨设备学习证据与复习状态同步属于第八章正式发布 P0，不再是非目标。

**间隔复习专项验收标准（Given-When-Then）**：

- **AC-SR-01 查看登记**：Given 某次作答尚无查看记录，When 用户确认“查看答案”，Then 幂等写入 1 条 `reveal` 薄弱证据，掌握收益为 0，并进入薄弱闭环。
- **AC-SR-02 重复查看**：Given 同一作答尝试已确认查看，When 用户重复点击、刷新或返回后再次触发，Then 不新增薄弱证据、不重复插题、不重复计分。
- **AC-SR-03 新尝试再查看**：Given 同一学习项在之后的新作答尝试中再次确认查看，When 本次尝试结算，Then 新增一条独立证据并重置当前掌握进度。
- **AC-SR-04 答错登记**：Given 用户完整提交但拼写错误，When 错误结果结算，Then 写入 `submitted-incorrect` 薄弱证据；未填完整提交不产生该证据。
- **AC-SR-05 首次穿插窗口**：Given 新薄弱词产生且会话容量足够，When 后续其他题结算，Then 第 1 次复现在第 3～7 道其他学习项之间出现。
- **AC-SR-06 二次穿插窗口**：Given 第 1 次穿插已结算且仍有容量，When 后续继续学习，Then 第 2 次复现在再间隔 3～7 道其他学习项后出现。
- **AC-SR-07 不紧邻重复**：Given 同一学习项存在多个待复现机会，When 系统编排题序，Then 任意两次之间至少有 3 道其他学习项，不连续出现。
- **AC-SR-08 单词次数上限**：Given 同一学习项当天产生多条薄弱证据，When 计算日内穿插，Then 额外穿插仍最多 2 次，不按证据数无限复制。
- **AC-SR-09 会话上限**：Given 会话原计划题量和薄弱词数量已知，When 生成日内穿插，Then 总量不超过 8 道且不超过原计划题量 30% 向上取整后的较小值。
- **AC-SR-10 多词竞争**：Given 多个薄弱词同时合格，When 选择下一个穿插项，Then 先保证首轮覆盖，再按窗口关闭、证据数、距上次出现和随机打散规则选择。
- **AC-SR-11 剩余题量不足**：Given 会话剩余题量无法满足 3 道间隔，When 计算穿插，Then 不紧邻追加；保留到当天下一会话或 D+1。
- **AC-SR-12 默认曲线**：Given D0 产生薄弱证据且用户按时完成，When 每阶段均掌握合格答对，Then 到期节奏依次为 D+1、D+3、D+7、D+14，并在 D+30 进入维护复习。
- **AC-SR-13 掌握资格**：Given 复习题从无答案字母状态开始，When 用户未查看、未用提示且完整拼写正确，Then 结果为 `clean-independent-correct`，本学习日可推进一个阶段。
- **AC-SR-14 提示不算掌握**：Given 用户使用提示字母后答对，When 结算，Then 结果为 `assisted-correct`，可反馈答对但不推进掌握阶段，原阶段顺延。
- **AC-SR-15 看后答对不算掌握**：Given 用户已查看答案后重试答对，When 结算，Then 保持 `correct-after-reveal`，不贡献跨日掌握证据。
- **AC-SR-16 同日不刷阶段**：Given 同一学习项当天已经产生一条掌握合格证据，When 当天再次无辅助答对，Then 只记加固，不推进第二个跨日阶段。
- **AC-SR-17 掌握退出**：Given S1～S4 在四个不同学习日均掌握合格答对，且 S4 不早于最近薄弱证据后第 14 学习日，When S4 结算，Then 标记 `mastered`、退出薄弱队列并安排 D+30 维护。
- **AC-SR-18 失败回退**：Given 学习项处于 S1～S4，When 用户答错或确认查看，Then 保留历史、重置为 S0，可按容量日内加固，并从下一学习日 S1 重启。
- **AC-SR-19 掌握后复发**：Given 学习项已 `mastered`，When 维护或普通练习中答错/查看，Then 立即恢复薄弱状态并从 S0 重启。
- **AC-SR-20 漏学顺延**：Given 某阶段到期但用户未学习，When 之后返回，Then 只显示当前阶段为逾期；合格完成后从实际完成日计算下一间隔，不同日阶段不压缩到同一天。
- **AC-SR-21 应用内队列**：Given 今日存在到期或逾期项，When 用户进入学习中心，Then 可看到真实数量、优先级和逐项复习原因，并能开始队列。
- **AC-SR-22 默认提醒**：Given 用户开启提醒且未改时间，When 当地学习日到 20:00 且仍有到期项并不在免打扰，Then 当天最多产生 1 次复习提醒。
- **AC-SR-23 通知未授权**：Given 用户未授权、拒绝或当前平台不支持外部通知，When 提醒时间到达，Then 不声称已送达，只保留应用内待复习状态和权限说明。
- **AC-SR-24 已完成防打扰**：Given 用户在提醒时间前完成所有到期项，When 提醒时间到达，Then 不发送当日复习提醒。
- **AC-SR-25 免打扰**：Given 提醒时间落入用户免打扰时段，When 到达该时间，Then 最多顺延到免打扰结束一次，不在时段内连续提醒。
- **AC-SR-26 离线**：Given 用户离线，When 到期或尝试进入复习，Then 不结算题目、不推进掌握、不伪记提醒送达；恢复后继续显示当前真实队列且不补发重复提醒。
- **AC-SR-27 跨时区**：Given 设备时区变化，When 用户尚未确认是否切换，Then 不静默改写学习日；确认切换后只重算未来到期/提醒，同一行程日不重复提醒或贡献两次跨日证据。
- **AC-SR-28 队列优先级**：Given 同时存在逾期、今日到期、日内穿插和新词，When 生成会话，Then 顺序优先级依次为逾期、今日到期、日内穿插、新词。
- **AC-SR-29 每日复习上限**：Given 跨日到期项超过 20 个，When 打开默认队列，Then 先呈现最多 20 个，剩余保持可见逾期并可主动继续，不被标为完成或未到期。
- **AC-SR-30 独立拼写正确率**：Given 一组已结算复习尝试，When 更新独立拼写正确率，Then 分子只含 `clean-independent-correct`，跳过、暂停、未完成和数据异常不进入分母。
- **AC-SR-31 连续学习与连对**：Given 用户仅查看答案、收到提醒或打开队列，When 更新连续学习与连对，Then 不新增学习日；查看/答错中断连对，辅助答对不恢复连对。
- **AC-SR-32 原因与历史**：Given 任一学习项进入复习，When 用户查看原因或历史，Then 能看到证据类型、时间/时区、辅助暴露、结果、阶段变化、到期日及跳过/暂停/重置原因。
- **AC-SR-33 跳过**：Given 学习项当天首次被跳过，When 队列继续，Then 它移到队尾且不计对错；当天第 2 次跳过则顺延下一学习日，不立即反复出现。
- **AC-SR-34 暂停与恢复**：Given 用户暂停学习项 1/3/7/30 个学习日，When 暂停期内生成队列或提醒，Then 该项不出现且阶段不变；恢复时回到暂停前阶段，不补造多次复习。
- **AC-SR-35 重置**：Given 用户明确确认重置掌握进度，When 重置完成，Then 当前阶段回到 S0、下一学习日进入 S1，重置前历史仍可追溯。
- **AC-SR-36 数据异常**：Given 学习项缺少目标答案/身份或到期时间非法，When 系统准备出题，Then 不计错、不推进，生成单一可解释的数据异常状态并继续下一可用题。

### 4.3 AI口语陪练（核心功能）

**功能描述**：24小时在线的AI私教，支持场景化角色扮演和自由对话，帮你练表达、纠语法、学地道说法。**MVP阶段不做发音评分和发音纠正**，降低实现难度，专注把内容反馈做好。支持文字输入，也支持语音转文字输入。

#### 4.3.1 场景对话模式
- **内置场景**（MVP 20个）：
  - 日常：自我介绍、餐厅点餐、购物、问路、看医生、机场、酒店
  - 职场：面试、工作汇报、邮件沟通、会议发言、商务谈判
  - 考试：雅思口语Part1/2/3、四六级口语
  - 旅游：海关、租车、景点、拍照
- **对话流程**：
  1. 用户选场景 → AI简单说下背景和你的角色，直接开始
  2. AI先开口，用户打字或者语音转文字回答
  3. AI自然回应，对话中不打断你
  4. 对话5-10轮结束 → 给你反馈总结

#### 4.3.2 自由对话模式
- 和AI随便聊任何话题，想聊什么聊什么
- AI根据你的水平调整用词难度
- 随时可以问"这个词什么意思""这句话怎么说更好"
- AI主动引导话题，不会冷场

#### 4.3.3 对话后反馈
- 语法错误列表：哪里错了、为什么错、正确说法是什么
- 用词建议：哪些词用的好，哪些词可以换更地道的说法
- 重点句型：这次对话里学到的好句子，标清楚什么场景用
- 薄弱点提醒：你经常犯的语法错误、常用错的词
- 本次对话学到的新词/新表达汇总

#### 4.3.4 实时智能辅助（对话中，核心差异化功能）
对话过程中不打断你，自然提供帮助，像真的私教一样：

1. **中英混杂随便说**
   - 不会说的词直接说中文就行，AI完全能懂
   - 比如你说"我今天要去机场接我的client"，AI正常接话，结束后告诉你"client在这里更常用colleague/customer"
   - 整句说中文也可以，AI帮你翻译成英文然后继续对话

2. **智能纠错不生硬**
   - 你说中式英语、用词错了、语法错了，AI**先正常接话回应你**，不打断对话，不让你尴尬
   - 先分析你想表达什么意思，再用小字温柔提示："我猜你想说的是XXX对不对？更自然的说法是XXX"
   - 绝对不说"你错了""不对"这种打击人的话
   - 比如你说"I very like it"，AI先正常回你"I like it too! 😊"，然后小字提示："对了，very不能直接修饰动词哦，你可以说I really like it 或者 I like it very much"
   - 目的是让你敢开口，不是一上来就挑错打击信心

3. **用词分析和扩展**
   - 你用了一个词，AI先理解你想表达的意思，再告诉你：
     - 如果用错了："你这里是不是想表达XX的意思？这个词更常用在XX场景，这里用XX更合适"
     - 如果用对了但有更好的："这个词用的不错！同样的意思还可以说XXX/XXX，更地道"
     - 如果用了母语者基本不用的词："这个词 native speaker 日常很少说，大家一般说XXX"
   - 不是只说"错了/对了"，而是给你讲清楚为什么、怎么更好

4. **分场景给建议**
   - 职场场景：告诉你"刚才那句I think，职场更委婉的说法是I suppose/From my perspective"
   - 日常场景：告诉你"朋友之间说谢谢，Cheers/Thanks比Thank you更自然"
   - 考试场景：告诉你"雅思口语这个问题，用这个句型分数更高"

5. **卡壳救星**
   - 想不起来怎么说，直接打"怎么说""提示一下"
   - 半天没说话（10秒以上），AI主动给你提示"你可以这么说：XXX"
   - 不会让你僵在那里

**验收标准**：
- [ ] AI回应自然，不生硬，符合场景逻辑，不会因为你说中文/说错就卡壳
- [ ] 实时提示不打断对话，不突兀，不让你觉得尴尬
- [ ] 反馈具体可操作，每个错误都讲清楚为什么错、怎么改
- [ ] 词汇建议分场景，职场/日常/考试的说法不一样
- [ ] 支持文字输入，也支持语音转文字输入
- [ ] 对话响应快，流式输出，不用等半天
- [ ] 至少20个常用场景
- [ ] 卡壳会主动提示，不会冷场
- [ ] 界面极简，打开就能聊，没有多余按钮

---

### 4.4 今日学习

**功能描述**：打开APP就知道今天学什么，不用选、不用想，零学习成本。界面只有两个大按钮：「背单词」「练口语」，点进去直接开始。

**设计原则：极致简单**
- 首页不搞复杂的图表、任务列表、打卡、成就、积分
- 打开就两个按钮，想背单词点单词，想练口语点口语
- 学完就走，没有任何多余的东西
- 学习进度AI自动记，不用用户操心

**验收标准**：
- [ ] 新用户打开3秒知道怎么用，不需要引导
- [ ] 首页没有多余按钮、广告、弹窗
- [ ] 点按钮直接开始学习，不需要选级别、选课程、选词书
- [ ] 学过的单词自动安排复习，不用用户管
- [ ] 所有设置藏在二级页面，首页只放最核心的功能

### 4.5 简单统计

**功能描述**：只给用户最关心的几个数字，不做复杂图表，不搞打卡徽章那些花里胡哨的。

**只显示这几个数**：
- 已经学了多少个单词
- 一共练了多久口语
- 最近常错的语法点

**验收标准**：
- [ ] 数字清晰，一眼能看到
- [ ] 没有复杂图表、没有排行榜、没有成就系统
- [ ] 藏在个人中心里，不放在首页打扰用户

## 八、v1.4 正式发布完整性范围

### 8.1 “全功能完成”的产品定义

AI English Learning 只有在本章全部 P0 能力使用真实服务、真实学习数据完成端到端验收后，才可称为“全功能完成”。当前 Word 本机纵切、`docs/02-architecture.md` v1.1 与 `docs/03-dev-tasks.md` v1.1 是可继续保留的有效子范围，但只覆盖单词学习的一部分，不能代表本产品已经完成，也不能直接作为完整发布计划。

以下情况均不得作为完成证据：Mock／脚本对话、仅浏览器临时状态、只在单设备生效、静态词库占位、假语音、禁用入口、空后端、预置统计、接口返回 HTTP 200 但业务结果错误，或用演示／种子数据冒充真实用户结果。真实依赖暂时不可用时可以进入明确、受控且可恢复的降级状态，但降级不能伪装成成功。

### 8.2 完整 P0 能力矩阵

| 能力域 | P0 正式发布范围 | 完成证据 |
|---|---|---|
| 账号与身份 | 多个独立注册用户可登录；每个账号一个学习者档案；游客仅体验，不计完整功能 | 两个账号数据隔离、登录恢复、退出与会话失效通过 |
| 定级与学习计划 | 完成 A1–C2 定级，记录题目／规则版本、结果和生成时间，并形成可解释的初始计划 | 真实作答可复算，未知或失败不伪造等级 |
| 智能词库 | 使用版本化真实词条、释义、例句、可接受答案与适用等级生成学习内容 | 活跃题目字段完整、版本可追溯、缺项不出题 |
| Word 学习 | 行内字母槽、检查、提示、查看答案、结果与下一题状态完整可用 | v1.3 的 AC 全部通过且数据写入服务端 |

| 数据权利 | 用户可查看保存范围、导出个人学习数据、删除账号及个人数据 | 导出可读，删除有进度、结果与备份到期说明 |

### 8.3 用户与账号边界

- 正式发布支持**多用户、单账号单学习者档案**。不同账号的身份、定级、目标、词库进度、薄弱证据、对话历史、语音记录、统计和设置必须隔离。
- 游客可以体验不涉及长期记忆的有限流程；游客状态必须清楚标记，关闭会话可能丢失的数据须提前说明。游客不能作为账号、跨设备、历史、导出或删除能力的验收主体，也不能用预置游客记录冒充真实用户进度。
- 本期不提供家庭／组织下的多个子档案、教师班级管理、社交关系、排行榜或付费权益。
- 登录失效、账号被删除、无权限访问或用户切换账号时，不得显示上一账号的任何个人内容；缓存清理与界面状态必须同步完成。

### 8.4 服务端学习记忆与跨设备语义

- 服务端保存可追溯的学习事件和由事件推导的当前状态，至少覆盖：题目身份、词条／规则版本、作答尝试、提示使用、查看答案、错误、独立答对、复习阶段、到期日、暂停／跳过／重置、计划完成、统计和更新时间。
- 查看答案或完整拼写错误必须形成幂等薄弱证据；同一尝试重复提交、刷新或网络重试不得重复计数。不同尝试再次查看或答错应形成新的历史证据。
- 多端同时产生结果时不得按“最后页面覆盖全部状态”处理。不可逆的查看／答错证据不得丢失；复习阶段只按已确认有效的事件推进，冲突必须给出可追溯结果。
- 在线设备完成一次成功写入后，另一在线设备在下一次主动刷新、重新进入页面或自动同步中应在 10 秒内看到收敛结果；离线期间不结算学习结果，恢复连接后需让用户确认重试，不能暗中补造答题。
- 服务端不可用时，用户可浏览明确允许的受控降级内容，但不得把未确认结果显示为“已保存”“已掌握”或“已同步”。

### 8.5 定级、词库与推荐真实性

- 定级覆盖产品声明的 A1–C2 能力区间。结果必须带评估版本、完成时间、有效作答和置信／限制说明；中断、答案不足或评分失败时保持“未完成／无法判定”，不得生成默认等级冒充结果。
- 智能词库中的每个可出题词条至少具有稳定身份、词形、释义、适用等级、例句、目标答案、可接受答案、来源／版本和有效状态。缺少目标答案或身份的词条进入数据异常，不得出题或计错。
- 每日新词和复习任务须说明推荐原因，例如定级、用户目标、到期复习或薄弱证据；不要求公开算法实现，但不得用完全随机或固定演示列表冒充个性化计划。
- 词条或可接受答案升级时，历史事件保留当时版本；新旧版本的复习迁移必须可解释，不得把版本变化当成用户答错。

### 8.6 真实 AI 对话与真实语音

- 20 个场景对话和自由对话均调用真实 AI 能力。固定欢迎语、示例回复或脚本回放只能用于说明和测试，不能成为正式对话结果。
- AI 回复需结合用户确认的等级、当前场景和本轮上下文；事实性建议、纠错与推荐需明确是模型生成。模型不得声称访问了未提供的个人事实。
- 对话反馈至少区分原句、建议表达、语法／用词说明和用户可继续练习的动作。基于转写文本的反馈属于 P0；声学发音评分与音素级诊断不属于本期。
- 真实语音包含麦克风录音、语音转写和 AI 回复语音播放。权限未授权、用户拒绝、无有效音频、识别失败、播放失败或服务限流时，必须保留可用的文字输入／显示，并说明失败与重试方式。
- AI、语音或内容安全服务全部不可用时，不得返回缓存脚本并标为新回复；应保留已确认历史、标记服务不可用并提供安全重试。
- 对话历史的保存范围、保留期、是否用于后续个性化和是否发送给第三方模型必须在用户使用前可查；未获授权的数据不得被静默用于训练或二次用途。

### 8.7 统计、连续学习与掌握口径

- “独立正确”只统计未查看答案、未使用泄露答案辅助且完整拼写正确的尝试；`revealed`、`assisted-correct` 和 `correct-after-reveal` 必须单列，不能计入独立正确率。
- 连续学习按用户所在学习日是否完成当日最低有效学习要求计算；查看答案可以推进题量但不能独立贡献正确或掌握。时区变更不得补造或删除已经确认的学习日。
- 掌握度来自 v1.3 规定的跨日独立正确证据；统计页必须能解释“为什么进入复习／为什么掌握／为什么回退”。
- 学习时长只累计应用实际处于学习活动的可解释区间；后台挂起、长时间无操作或失败等待不得无限累加。
- 所有展示指标必须能由保存的原始事件和公开口径复算；重算差异超过 0 时进入数据异常并不得继续展示为确定事实。

### 8.8 隐私、导出与删除

- 产品需按数据类型说明收集目的、必要性、保存位置、保留期、第三方接收方和用户控制，至少覆盖账号、定级、学习事件、对话、语音／转写、提醒设置和诊断日志。
- 语音原始音频默认只为本次识别所需；若需长期保存，必须另行明确选择。未选择长期保存时，不得用模糊条款代替授权。
- 用户可导出机器可读数据和人类可读摘要；导出至少包含账号资料、学习计划、学习／复习事件、统计口径、对话历史保存部分、设置、生成时间和数据版本。
- 删除账号后应立即撤销登录与正常访问，并在 24 小时内删除活动数据；备份中的残留按公开周期、最长 30 天自然到期且不得恢复为活动账号。法律必须保留的最小记录须单列目的和期限。
- 导出或删除失败不得显示成功；用户可查看请求时间、当前状态、失败原因和重试／申诉方式。

### 8.9 异常、质量与受控降级

| 场景 | 产品行为 |
|---|---|
| 身份服务不可用 | 不进入其他账号，不显示伪登录；保留安全重试 |
| 学习写入超时 | 保持“待确认／未保存”，幂等重试后只结算一次 |
| 词库字段缺失 | 隔离异常题，不计错，继续下一可用题并留下原因 |
| AI／语音单项不可用 | 明确该能力降级；其他真实能力可继续，不用 Mock 填补 |
| 全部业务服务不可用 | 显示未就绪和最近成功时间，不把静态页面称为可用应用 |
| 历史与统计不一致 | 冻结受影响指标为“核对中”，保留原始证据，不静默改数 |
| 多端冲突 | 合并不可逆证据，说明最终状态；不以最后页面整体覆盖 |
| 删除／导出处理中 | 展示真实进度；未完成前不声称已删除／已导出 |

正式发布还必须满足：完整简体中文；320px 起响应式可用；键盘全流程；屏幕阅读器状态与错误可感知；200% 放大不丢失核心内容；健康与就绪分离；安全与权限检查；备份恢复和版本回滚演练；相关单元、契约、集成、端到端与回归测试全部通过，且无未关闭 P0／P1 缺陷。

### 8.10 v1.4 Given-When-Then 验收标准

- **AC-AEL-REL-01 多用户隔离**：Given 账号 A 与 B 都有学习数据，When 任一账号登录、退出并切换，Then 只能读取和修改本账号数据，跨账号泄露记录为 0。
- **AC-AEL-REL-02 游客边界**：Given 用户以游客进入，When 查看身份与保存说明，Then 明确可体验范围、数据丢失条件和升级路径，且游客演示记录不进入注册用户统计。
- **AC-AEL-REL-03 登录恢复**：Given 已登录用户刷新或在另一设备登录，When 身份有效，Then 恢复同一学习者档案；身份无效时安全退出且不展示缓存个人数据。
- **AC-AEL-REL-04 定级真实性**：Given 用户完成有效定级，When 查看结果，Then 返回 A1–C2 中的结果、评估版本、完成时间与限制；中断或失败时不生成默认等级。
- **AC-AEL-REL-05 词条完整性**：Given 活跃题目准备出题，When 校验词条，Then 100% 具有稳定身份、版本、目标与可接受答案；缺失项被隔离且不计错。
- **AC-AEL-REL-06 推荐原因**：Given 今日任务包含新词或复习，When 用户查看任务原因，Then 每项可归因于等级、目标、到期或薄弱证据之一。
- **AC-AEL-REL-07 查看持久化**：Given 用户确认查看答案，When 刷新、重登或换设备，Then `reveal` 薄弱证据仍存在且不计独立答对。
- **AC-AEL-REL-08 日内复现**：Given 用户查看或答错且今日仍有容量，When 后续完成规定窗口，Then 该词按 v1.3 去重和间隔规则复现；不足容量时显示真实顺延原因。
- **AC-AEL-REL-09 跨日曲线**：Given 薄弱词形成 S0，When经过 D+1/3/7/14 与 D+30，Then 队列按服务端学习日生成，漏学只顺延、不补造完成。
- **AC-AEL-REL-10 掌握回退**：Given 单词已掌握，When 后续独立答错或再次查看，Then 立即恢复薄弱状态并保留此前掌握历史。
- **AC-AEL-REL-11 写入幂等**：Given 同一作答因重试被提交多次，When 服务恢复，Then 只形成一次结算和一次相应证据。
- **AC-AEL-REL-12 多端收敛**：Given 两个在线设备操作同一学习项，When 任一设备成功同步并触发另一设备下一次同步，Then 10 秒内收敛且查看／答错证据无丢失、阶段无重复推进。
- **AC-AEL-REL-13 离线边界**：Given 设备离线，When 用户尝试结算题目，Then 不显示已保存、已同步或已掌握；恢复后由用户重试并幂等结算。
- **AC-AEL-REL-14 二十场景可用**：Given 正式环境启用 20 个场景，When 逐场景发起有效输入，Then 20/20 均由真实 AI 返回上下文相关回复或明确真实失败，脚本冒充次数为 0。
- **AC-AEL-REL-15 自由对话**：Given 用户进入自由对话，When 连续发送至少三轮内容，Then AI 保持本轮上下文并按用户等级反馈，不虚构未提供的个人事实。
- **AC-AEL-REL-16 对话反馈**：Given 用户完成一轮对话，When 查看反馈，Then 能区分原句、建议表达、语法／用词说明和下一步动作，模型生成身份明确。
- **AC-AEL-REL-17 真实转写**：Given 用户授权麦克风并提交有效语音，When 识别完成，Then 显示实际转写供确认；预置或固定转写冒充次数为 0。
- **AC-AEL-REL-18 语音降级**：Given 麦克风拒绝、静音、识别或播放失败，When 用户继续学习，Then 文字路径仍可用并显示原因与重试，不伪造语音成功。
- **AC-AEL-REL-19 AI 全失败**：Given AI 服务不可用，When 用户发送消息，Then 不返回缓存脚本作为新回复，保留输入和历史并展示未完成与重试。
- **AC-AEL-REL-20 独立正确率**：Given 历史同时含独立答对、提示答对、查看后答对和错误，When 计算正确率，Then 分子只含独立答对且各辅助结果单列。
- **AC-AEL-REL-21 连续学习**：Given 用户只查看答案并完成题量，When 结算学习日，Then 题量可推进但不增加独立正确或掌握证据，连续规则按公开最低要求计算。
- **AC-AEL-REL-22 统计复算**：Given 选定账号与时间范围，When 从历史事件复算，Then 学习量、时长、正确率、查看次数、掌握和到期数与展示值一致。
- **AC-AEL-REL-23 时区变化**：Given 用户改变学习时区，When 查看历史，Then 已确认学习日不被重写，新任务按生效后的时区生成并有说明。
- **AC-AEL-REL-24 数据说明**：Given 用户首次使用涉及个人数据的能力，When 查看隐私说明，Then 能找到数据类型、目的、保留期、第三方和控制方式。
- **AC-AEL-REL-25 语音最小化**：Given 用户未选择长期保存音频，When 一次识别结束，Then 原始音频不进入长期个人历史，转写保存状态按说明执行。
- **AC-AEL-REL-26 数据导出**：Given 用户申请导出，When 任务成功，Then 获得人类可读摘要与机器可读数据，覆盖已声明范围并带版本、生成时间和口径。
- **AC-AEL-REL-27 账号删除**：Given 用户完成删除确认，When 请求受理，Then 登录立即失效、活动数据 24 小时内删除，备份残留期限不超过公开的 30 天。
- **AC-AEL-REL-28 删除失败**：Given 删除未完成，When 用户查询，Then 不显示“已删除”，而显示状态、原因和重试／申诉方式。
- **AC-AEL-REL-29 未就绪**：Given 业务进程可响应但关键数据或依赖未就绪，When 检查应用，Then 健康与就绪可分别判断，页面不以 HTTP 200 声称功能完成。
- **AC-AEL-REL-30 错误恢复**：Given 写入、AI、语音或词库发生单项失败，When 故障恢复并重试，Then 未完成动作可安全继续且不会重复计分或丢失已确认数据。
- **AC-AEL-REL-31 简体中文**：Given 用户选择简体中文，When 遍历全部 P0 路径，Then 导航、操作、状态、错误、空状态、统计、隐私和移动端文案中文覆盖率为 100%。
- **AC-AEL-REL-32 移动与无障碍**：Given 320px 视口、键盘、屏幕阅读器或 200% 放大，When 完成登录、学习、查看答案、对话、统计和数据权利路径，Then 核心内容与操作均可达且状态不只依赖颜色。
- **AC-AEL-REL-33 安全隔离**：Given 未登录、无权限或已删除账号，When 请求个人学习、对话、导出或删除数据，Then 被安全拒绝且响应和日志不泄露敏感内容。
- **AC-AEL-REL-34 备份恢复**：Given 使用最近一次合格备份恢复，When 核对账号与学习事件，Then 已承诺恢复点内的数据完整、账号隔离不变并形成演练证据。
- **AC-AEL-REL-35 版本回滚**：Given 新版本关键 P0 验证失败，When 执行已验证回滚，Then 上一可用版本恢复且不回退或重复已确认学习事件。
- **AC-AEL-REL-36 完成门**：Given 准备声明全功能完成，When 审查 P0 矩阵、联调、测试、健康／就绪、安全、备份和回滚证据，Then 全部通过且未关闭 P0／P1 缺陷为 0；Mock、禁用入口、空后端和仅 HTTP 200 证据数量均为 0。
