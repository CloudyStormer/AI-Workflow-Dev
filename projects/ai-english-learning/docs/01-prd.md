## 一、产品定位

**一句话定位**：你的24小时AI英语私教，基于大模型提供个性化学习路径、场景化口语陪练、智能单词记忆，让学英语像聊天一样简单。

**核心价值**：
- 🎯 **真正个性化**：不是固定课程，AI根据你的水平、目标、薄弱点定制学习内容
- 🗣️ **敢开口**：24小时AI陪练，不用约课不怕尴尬，从单词到自由对话循序渐进
- 🧠 **记得住**：结合艾宾浩斯遗忘曲线+AI语境记忆，不做无用功
- 📱 **随时学**：手机PC多端同步，碎片时间就能学

## 四、核心功能详细说明

### 4.1 AI水平定级测试

**功能描述**：新用户首次进入，通过10分钟左右的AI自适应测试，评估用户当前英语水平。

**用户流程**：
1. 新用户进入 → 只问两个问题：① 你学英语是为了什么？（职场/考试/日常/陪孩子）② 你现在大概什么水平？（零基础/入门/中级/高级）
2. 可选做5分钟快速测试（选择题：词汇+语法+阅读），也可以直接跳过
3. 直接进入首页开始学习，不搞复杂的注册和问卷

**验收标准**：
- [ ] 新用户30秒内进入学习界面，不需要填一堆信息
- [ ] 测试题目10道选择题以内，时长不超过5分钟
- [ ] 支持跳过所有引导，直接开始用
- [ ] 学习过程中AI会根据你的表现动态调整难度，不需要一开始就定死

---

### 4.2 智能单词记忆

**功能描述**：不是传统的单词表，AI根据用户水平、记忆曲线、学习目标智能安排单词学习和复习。

**核心逻辑**：
1. **单词推荐**：根据用户目标（职场/考试/日常）推荐对应词表
2. **记忆算法**：艾宾浩斯遗忘曲线，每个单词有熟练度，熟练度越低复习间隔越短
3. **双模式自由切换**：
   - **📖 纯背单词模式**：不考试、不做题，就安安静静看单词
     - 显示单词、音标、中文意思
     - 给3个实用场景例句
     - 讲清楚这个单词怎么用、常见搭配、和同义词的区别
     - 认识就点"下一个"，不认识就点"再看看"，简单放松
   - **✏️ 填空练习模式**：主动回忆，记得牢
     - 给一个缺了单词的句子 + 中文意思
     - 句子缺词位置本身就是唯一答案入口；每个待填英文字母对应一个字母槽，页面不再提供句子下方的独立答案输入框
     - 初始空槽直接表达答案长度；例如目标词为 `apple` 时显示 `_____`，输入 `a` 后显示 `a____`，继续输入依次形成 `ap___`、`app__`、`appl_`、`apple`
     - 系统随机提示字母固定在对应位置，并与用户已输入字母合并为同一个答案；输入过程中不得重排提示或覆盖用户已输入内容
     - 用户键入字母时依次填入下一个未填写、非提示的字母槽；退格删除最近一个可编辑字母，也可定位到任一可编辑槽修改
     - 支持粘贴完整答案或剩余字母；完整答案按目标位置与既有提示合并，剩余字母按未填写槽位依次填入，固定分隔符不重复占位
     - 连字符、撇号、空格等分隔符按目标词原样固定显示，不作为可编辑字母；输入、退格和粘贴时自动跨过
     - 答案字母不区分大小写；本期不以大小写作为拼写题考点，非答案字符不得进入字母槽
     - **同义词兼容规则**：同义词仍可作为可接受答案，但只有字母数量、分隔符和当前提示字母均与本题槽位兼容的候选才能在本题判为正确；不兼容的同义词在答后扩展中展示，不得让用户在无法容纳它的固定槽位中作答
     - 用户提交时，未填完整则提示剩余字母数并回到首个未填槽，不判为错误；填完整后再判断答案
     - 答案错误时保留用户输入和系统提示，允许直接退格、定位并修改后重新提交，不自动跳题或用正确答案覆盖输入
     - 答案正确时给出明确反馈；用户通过“下一题”操作或键盘确认进入下一题，新题清空上一题输入并生成本题稳定的随机提示
     - 答题完成或主动查看答案后给出扩展：这个词的其他同义词、常见搭配、用在什么场景
     - 错了不打击；用户可继续修改重试，也可主动查看答案并结束本轮独立作答
4. **应用**：在口语对话中遇到刚学的单词，AI会主动用，帮你巩固

#### 4.2.1 “查看答案”产品规则

**目标**：让确实不会作答或希望核对的用户，主动结束本轮独立作答后，直接在现有句中行内字母槽看到完整正确答案；同时保证“看过答案”不会被计作独立答对或提高熟练度。

**1. 可用时机与触发条件**

- “查看答案”是填空练习中的 P0 次要操作。题目加载后，在未作答、部分作答、提交未完成和提交错误状态均可使用；不要求先提交，也不设置倒计时或自动揭晓。
- 用户已经独立答对时，正确答案已经完整呈现，“查看答案”不再可触发，也不得补记为看过答案；此时主操作保持为“下一题”。
- 首次触发只进入误触确认，明确告知“查看后本题不计为独立答对”；只有用户再次明确确认才揭晓。取消、按 `Esc` 或离开确认状态均不改变答案和记录。
- 同一题重复确认必须幂等：只产生一次揭晓记录，不重复结算进度、正确率或复习记录。

**2. 正确答案的直接展示方式**

- 确认查看后，系统用本题标准目标词完整替换现有句中行内字母槽内容；不得新增句子下方答案框、独立答案卡或要求用户跳转后才能看到答案。
- 分隔符、大小写规则与现有字母槽一致。存在可接受同义词时，揭晓当前槽位对应的标准目标词；其他同义词继续放在答后扩展，不切换槽位长度。
- 字母槽进入只读的“正确答案，已查看”状态，状态表达不得只依赖颜色。系统须保留揭晓前的空白、部分输入或错误输入快照，用于本题结果和复习记录，但不在槽中与正确答案混排。
- 揭晓前不得通过可见文案、可访问名称、复制内容或其他前端状态泄露完整答案。

**3. 各答题状态下的行为**

| 揭晓前状态 | 确认查看后的结果 | 结果分类 |
|---|---|---|
| 未作答 | 直接填入完整标准答案，槽位只读 | `revealed` |
| 部分作答 | 保存部分输入快照，再填入完整标准答案 | `revealed` |
| 已提交但未填完整 | 保留“不判错”的既有语义，保存输入快照后揭晓 | `revealed` |
| 已提交且答错 | 保存错误答案与提交结果，再揭晓 | `revealed` |
| 已提交且答对 | 不再触发查看答案，保持独立答对结果 | `independent-correct` |

**4. 揭晓后的编辑、重试、提交与下一题**

- 揭晓后，本轮独立作答结束：字母槽不可编辑，“提示”和“检查答案”不可使用，“下一题”立即可用。
- 用户可以选择“重新作答本题”。重试会清空可编辑字母，恢复本题最初的稳定提示字母，并重新允许编辑、提示和检查；不得生成另一套随机提示来降低或提高难度。
- 揭晓后的重试属于辅助练习。用户可以重新提交并获得对错反馈，但即使答对也只记为 `correct-after-reveal`，不得改写为独立答对、提高本题正确率或获得掌握度收益。
- 用户选择“下一题”后才把本题计入今日题量进度；仅打开确认但未确认，不得结算或推进本题。

**5. 计分、正确率、连续学习、进度与复习记录**

- 本题结果至少区分：`independent-correct`（揭晓前独立答对）、`revealed`（已查看答案）、`correct-after-reveal`（查看后重试答对）和作答中的错误/未完成状态。
- 正确率分子只计入揭晓前独立提交正确的题目。已确认揭晓且通过“下一题”结算的题目计入分母但不计入分子，避免通过查看答案抬高正确率；查看后重试答对也不回填分子。
- 确认揭晓会中断“连续答对”；不能把查看答案或查看后答对计入连对。
- 已揭晓题在进入下一题时可以完成今日题量进度，但必须标记为“已复习/未独立答对”，不得显示为完成一道正确题。
- “连续学习天数”沿用既有按学习日/会话完成的规则：单独点击查看答案不会新增学习天数；包含揭晓题的已完成学习会话仍可算作学习日，但不会产生正确率或熟练度收益。
- 复习记录须保存揭晓时间、揭晓前状态、揭晓前输入快照、标准答案、是否查看后重试及最终辅助练习结果。查看答案不得提升单词熟练度或延长复习间隔；该词至少按“答错”基线进入待复习，后续复习时间不得晚于答错场景。

**6. “提示”“检查答案”“查看答案”的关系**

- **提示**：只补充部分稳定字母，用户仍处于独立作答，可继续编辑和提交；提示使用情况可单独记录，但不直接结束本题。
- **检查答案**：校验当前完整输入；未填完整时只提示剩余字母数，不判错、不揭晓。
- **查看答案**：主动结束本轮独立作答并揭晓完整答案，必须经过一次明确确认；它不是更多提示，也不能由“检查答案”自动触发。
- 揭晓后，提示与检查答案保持不可用，直至用户主动选择“重新作答本题”。不得把双击、长按、全局回车或连续答错隐式解释为查看答案。

**7. 键盘、移动端与无障碍约束**

- “查看答案”必须可以通过顺序键盘焦点到达，并支持 `Enter` 或空格触发；确认状态支持 `Esc` 取消。不得绑定全局 `Enter` 直接揭晓答案。
- 移动端确认揭晓后收起软键盘，保证正确答案、结果状态和“下一题”仍在当前任务流内可访问；不要求用户横向滚动或重新打开键盘才能继续。
- 揭晓后将焦点移动到结果摘要，或以等效方式立即播报结果；字母槽组的可访问名称至少表达“正确答案、已查看”，并能按字符正确读出字母和固定分隔符。
- 未作答、部分作答、错误、正确、已查看和查看后答对均须有非颜色状态文本；确认提示、只读状态和下一步操作对屏幕阅读器可感知。

**8. 边界条件与不做项**

- 确认前切换学习模式、离开本题或取消确认，不产生查看记录；确认后离开或刷新时，已查看状态和复习记录不得回退成未查看。
- 1～2 个字母短词以及含空格、连字符、撇号的答案仍按完整标准答案揭晓，固定分隔符不参与编辑或计数。
- 本次不做倒计时自动揭晓、连续答错自动揭晓、看答案奖励积分、查看后恢复独立答对资格、答案历史同步、跨设备记录同步或复习算法重构。
- 本次只定义产品行为，不修改 `docs/03-ui-prompt.md`、`ui/`、前端代码、后端代码，也不替代 UI/UX 对视觉层级和组件形态的后续设计。

**用户流程**：
1. 打开APP → 点"背单词"
2. 顶部可以切换「纯背模式」或「填空模式」，默认先纯背后练习
3. 先复习今天该复习的单词，再学新单词
4. 填空题可继续作答、检查答案，或确认“查看答案”后直接在原字母槽看到完整答案；揭晓后可下一题或重新作答本题
5. 完成今天的量自动结束，不搞打卡积分那些花里胡哨的

**验收标准**：
- [ ] 支持不同目标词库（日常/四级/六级/雅思/职场）
- [ ] 每个单词至少3个实用例句，不是陈旧的教科书句子
- [ ] 双模式切换流畅，纯背模式简单放松，填空模式交互爽快
- [ ] 填空模式按可接受答案集合判定；槽位不兼容的同义词只用于答后扩展，不造成“语义正确但无法输入”的死路
- [ ] 填完不管对错都给扩展：同义词、搭配、用法，不是只说对错
- [ ] 句子下方不存在独立答案输入框，唯一答案入口位于句子缺词处；目标词 `apple` 输入 `a` 后显示 `a____`，连续输入可完成 `apple`
- [ ] 随机提示字母与用户输入稳定合并；继续提示或更换提示不得删除、移动或覆盖用户已输入字母
- [ ] 支持连续输入、退格、定位修改和粘贴；输入或粘贴完整答案及剩余字母均能按槽位正确合并
- [ ] 提交未完成答案时不判错，并告知剩余字母数；错误答案保留且可修改重交；正确答案可通过明确操作进入下一题
- [ ] 1 个字母的短词不直接提示答案；2 个字母的短词即使有提示也至少保留 1 个字母让用户填写，且输入、提交和修改流程完整
- [ ] 含连字符、撇号或空格的答案固定显示分隔符，输入、退格、粘贴和校验均只在字母槽上推进，不因分隔符错位
- [ ] 移动端点击句中槽位能调起可用的英文文本键盘；软键盘出现后仍可看见当前作答位置、修改答案并提交，自动更正不得静默改写答案
- [ ] 仅用键盘即可聚焦答案、输入、定位、退格、粘贴、提交和进入下一题；焦点顺序连续可预期
- [ ] 辅助技术将整组字母槽识别为一个有名称的答案输入，能获知句子上下文、答案字母数、已输入数量、提示位置、剩余数量及正确/错误结果；状态表达不只依赖颜色
- [ ] 复习算法正常工作，每天自动安排需要复习的单词
- [ ] 支持标记熟词、收藏单词
- [ ] 界面极简，没有多余按钮和广告

**“查看答案”专项验收标准（Given-When-Then）**：

- **AC-RA-01 可用状态**：Given 填空题处于未答、部分作答、提交未完成或提交错误状态，When 用户查看可用操作，Then “查看答案”可触发，且无需先答错或等待倒计时。
- **AC-RA-02 正确状态**：Given 用户已在揭晓前独立答对，When 正确结果出现，Then 不再允许触发“查看答案”，结果保持 `independent-correct`。
- **AC-RA-03 误触保护**：Given 用户首次触发“查看答案”，When 尚未明确确认，Then 系统说明查看后不计独立答对，且答案、进度、计分和复习记录均不改变。
- **AC-RA-04 取消确认**：Given 查看答案确认已打开，When 用户取消、按 `Esc`、切换模式或离开本题，Then 不揭晓答案、不写入查看记录，并恢复原作答状态。
- **AC-RA-05 直接揭晓**：Given 用户明确确认查看，When 揭晓完成，Then 当前句中原字母槽直接显示完整标准答案，不新增句下答案框或跳转页面。
- **AC-RA-06 输入快照**：Given 揭晓前存在空白、部分输入或错误答案，When 用户确认查看，Then 系统保存揭晓前状态和输入快照，并以标准答案替换槽内可见内容。
- **AC-RA-07 槽位只读**：Given 答案已揭晓，When 用户尝试输入、粘贴、退格或定位修改，Then 槽位保持只读，并以非颜色方式表达“正确答案，已查看”。
- **AC-RA-08 提示与检查**：Given 答案已揭晓且未进入重新作答，When 用户检查可用操作，Then “提示”和“检查答案”不可用，“下一题”立即可用。
- **AC-RA-09 重新作答**：Given 答案已揭晓，When 用户选择“重新作答本题”，Then 清空可编辑字母、恢复原稳定提示集并重新允许作答，不生成新的提示集。
- **AC-RA-10 查看后答对**：Given 用户查看答案后重新作答并提交正确，When 系统结算，Then 结果为 `correct-after-reveal`，提供练习反馈但不计独立答对、正确率分子或熟练度收益。
- **AC-RA-11 正确率**：Given 已查看题通过“下一题”结算，When 更新正确率，Then 本题计入分母、不计入分子；仅揭晓前独立答对计入分子。
- **AC-RA-12 连续与进度**：Given 用户确认查看答案，When 结算本题，Then 连续答对被中断；进入下一题时今日题量可推进，但状态标记为“已复习/未独立答对”。
- **AC-RA-13 连续学习天数**：Given 用户仅确认查看答案但未完成既有学习日/会话条件，When 更新连续学习天数，Then 不新增学习天数；会话正常完成时可计学习日，但揭晓题不产生答对收益。
- **AC-RA-14 复习语义**：Given 本题被确认揭晓，When 写入复习记录和安排下次复习，Then 保存揭晓时间、前态、输入快照、标准答案、重试与最终结果，且复习不得晚于答错基线。
- **AC-RA-15 幂等性**：Given 同一题已成功揭晓，When 用户重复点击、双击或重复确认，Then 只保留一次揭晓与结算记录，不重复推进进度或改变统计。
- **AC-RA-16 键盘操作**：Given 用户仅使用键盘，When 依次聚焦并操作查看答案，Then 可用 `Enter`/空格触发、`Esc` 取消，且全局 `Enter` 不会直接揭晓。
- **AC-RA-17 移动端**：Given 移动端软键盘处于打开状态，When 用户确认查看，Then 软键盘收起，正确答案、状态和“下一题”仍可访问和操作。
- **AC-RA-18 无障碍播报**：Given 辅助技术正在读取页面，When 答案揭晓，Then 用户能立即获知“正确答案、已查看”、完整字母与分隔符、结果状态和下一步操作，且信息不只依赖颜色。
- **AC-RA-19 防答案泄露**：Given 用户尚未确认查看且未独立答对，When 使用可见内容、复制或辅助技术访问题目，Then 不得提前获得完整标准答案。
- **AC-RA-20 特殊答案**：Given 目标词为短词或含空格、连字符、撇号，When 用户确认查看，Then 完整标准答案按原结构显示，固定分隔符正确保留且不被计为可编辑字母。

### 4.3 AI口语陪练（核心功能）

**功能描述**：24小时在线的AI私教，支持场景化角色扮演和自由对话，帮你练表达、纠语法、学地道说法。**MVP阶段不做发音评分和发音纠正**，降低实现难度，专注把内容反馈做好。支持文字输入，也支持语音转文字输入。

#### 4.3.1 场景对话模式
- **内置场景**（MVP 20个）：
  - 日常：自我介绍、餐厅点餐、购物、问路、看医生、机场、酒店
  - 职场：面试、工作汇报、邮件沟通、会议发言、商务谈判
  - 考试：雅思口语Part1/2/3、四六级口语
  - 旅游：海关、租车、景点、拍照
- **对话流程**：
  1. 用户选场景 → AI简单说下背景和你的角色，直接开始
  2. AI先开口，用户打字或者语音转文字回答
  3. AI自然回应，对话中不打断你
  4. 对话5-10轮结束 → 给你反馈总结

#### 4.3.2 自由对话模式
- 和AI随便聊任何话题，想聊什么聊什么
- AI根据你的水平调整用词难度
- 随时可以问"这个词什么意思""这句话怎么说更好"
- AI主动引导话题，不会冷场

#### 4.3.3 对话后反馈
- 语法错误列表：哪里错了、为什么错、正确说法是什么
- 用词建议：哪些词用的好，哪些词可以换更地道的说法
- 重点句型：这次对话里学到的好句子，标清楚什么场景用
- 薄弱点提醒：你经常犯的语法错误、常用错的词
- 本次对话学到的新词/新表达汇总

#### 4.3.4 实时智能辅助（对话中，核心差异化功能）
对话过程中不打断你，自然提供帮助，像真的私教一样：

1. **中英混杂随便说**
   - 不会说的词直接说中文就行，AI完全能懂
   - 比如你说"我今天要去机场接我的client"，AI正常接话，结束后告诉你"client在这里更常用colleague/customer"
   - 整句说中文也可以，AI帮你翻译成英文然后继续对话

2. **智能纠错不生硬**
   - 你说中式英语、用词错了、语法错了，AI**先正常接话回应你**，不打断对话，不让你尴尬
   - 先分析你想表达什么意思，再用小字温柔提示："我猜你想说的是XXX对不对？更自然的说法是XXX"
   - 绝对不说"你错了""不对"这种打击人的话
   - 比如你说"I very like it"，AI先正常回你"I like it too! 😊"，然后小字提示："对了，very不能直接修饰动词哦，你可以说I really like it 或者 I like it very much"
   - 目的是让你敢开口，不是一上来就挑错打击信心

3. **用词分析和扩展**
   - 你用了一个词，AI先理解你想表达的意思，再告诉你：
     - 如果用错了："你这里是不是想表达XX的意思？这个词更常用在XX场景，这里用XX更合适"
     - 如果用对了但有更好的："这个词用的不错！同样的意思还可以说XXX/XXX，更地道"
     - 如果用了母语者基本不用的词："这个词 native speaker 日常很少说，大家一般说XXX"
   - 不是只说"错了/对了"，而是给你讲清楚为什么、怎么更好

4. **分场景给建议**
   - 职场场景：告诉你"刚才那句I think，职场更委婉的说法是I suppose/From my perspective"
   - 日常场景：告诉你"朋友之间说谢谢，Cheers/Thanks比Thank you更自然"
   - 考试场景：告诉你"雅思口语这个问题，用这个句型分数更高"

5. **卡壳救星**
   - 想不起来怎么说，直接打"怎么说""提示一下"
   - 半天没说话（10秒以上），AI主动给你提示"你可以这么说：XXX"
   - 不会让你僵在那里

**验收标准**：
- [ ] AI回应自然，不生硬，符合场景逻辑，不会因为你说中文/说错就卡壳
- [ ] 实时提示不打断对话，不突兀，不让你觉得尴尬
- [ ] 反馈具体可操作，每个错误都讲清楚为什么错、怎么改
- [ ] 词汇建议分场景，职场/日常/考试的说法不一样
- [ ] 支持文字输入，也支持语音转文字输入
- [ ] 对话响应快，流式输出，不用等半天
- [ ] 至少20个常用场景
- [ ] 卡壳会主动提示，不会冷场
- [ ] 界面极简，打开就能聊，没有多余按钮

## 五、非功能需求

### 性能需求
- 页面首屏加载时间 < 2秒
- 语音识别响应时间 < 1秒
- AI对话响应时间 < 2秒（流式输出）
- 支持1000人同时在线使用

### 兼容性需求
- PC端：Chrome、Edge、Safari最新两个版本
- 移动端：iOS Safari、Android Chrome，响应式适配
- 屏幕尺寸：支持320px（手机）到2560px（大屏）

### 安全需求
- 用户密码加密存储
- 对话数据加密传输
- 不泄露用户个人信息
- 内容安全：AI不生成违规内容

### 用户体验需求
- **零学习成本**：新用户打开就会用，不需要看教程、不需要引导
- **界面极简**：能少一个按钮就少一个按钮，没有多余元素，清爽干净
- 学习过程无广告、无弹窗、无推送打扰
- 操作反馈及时，点了就有反应
- 支持深色/浅色模式
