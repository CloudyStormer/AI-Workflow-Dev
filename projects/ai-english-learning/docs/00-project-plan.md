# AI英语智能学习 - 项目计划书

## 项目概述
- **项目名称**：AI英语智能学习（AI English Master）
- **项目目标**：打造一款基于大模型的AI驱动英语学习产品，支持手机端和PC端，提供个性化学习路径、AI口语陪练、智能单词记忆等核心功能
- **目标用户**：学生、职场人士、英语爱好者，覆盖零基础到中高级学习者
- **版本目标**：MVP版本，验证核心产品价值

## 核心功能范围（MVP）
1. AI水平定级测试
2. 智能单词记忆（艾宾浩斯+AI语境记忆）
3. AI口语陪练（多场景自由对话+发音纠错）
4. 个性化学习路径推荐
5. 学习数据统计
6. 多端支持（Web PC端 + 移动端H5）

## 风险评估
| 风险 | 影响 | 概率 | 应对方案 |
|------|------|------|----------|
| 大模型API响应慢 | 高 | 中 | 流式输出+缓存+loading优化 |
| 语音识别准确率 | 高 | 中 | 使用成熟ASR服务（豆包/OpenAI Whisper） |
| 发音纠错准确性 | 中 | 中 | 音素级评测+人工校验prompt |
| 多端兼容性 | 中 | 低 | 响应式设计+主流浏览器适配 |

## 技术栈（暂定）
- 前端：React + TypeScript + TailwindCSS
- 后端：Node.js + Express
- 数据库：SQLite（MVP阶段，后续可升级PostgreSQL）
- AI能力：豆包大模型API + 语音识别/合成
- 部署：Docker + 本地/云服务器
