## 1. 设计结论

本设计在超级无敌帅超超总提供的 13 项权威视觉母版上完成发布完整性增量，不重做品牌，不改变首页“背单词 / 练口语”双主入口，也不把工程状态做成监控后台。

设计把已批准 PRD v1.4、UI Prompt v1.0 与四项目真实可用产品增量统一为三条界面原则：

1. 学习任务始终优先：首屏先回答“现在可以做什么”，再解释服务与证据。
2. 真实性就近表达：任何目标态、示例数字、未接通能力、降级和未确认写入都在相关组件附近说明。
3. 正确禁用仍然可见：尚未就绪的 AI、语音、导出、删除或同步操作不会被假实现，也不会被悄悄隐藏；界面说明原因、影响和恢复动作。

当前事实不是“全功能已完成”：真实账号、词库、计划、服务端复习、真实 AI、STT、TTS、统计、跨设备同步、导出和删除尚未全部接通。本设计稿是目标态和状态规范，不是运行时完成证据。

## 3. 设计目标与非目标

### 3.1 目标

- 用户 3 秒内识别“背单词 / 练口语”两条主路径。
- 从账号、定级、计划、Word、复习、对话、语音、统计、同步到数据权利形成完整页面体系。
- 让 `未就绪 / 降级 / 失败 / 离线 / 保存尚未确认 / 冲突` 和正常态一样可理解、可恢复。
- 使用完整简体中文；内部键仅保留在开发附注，不裸露给用户。
- 1440、1024、390、320 独立编排；320 不是 390 的整体缩小。
- 键盘、屏幕阅读器、200% 放大和减少动态效果可完成 P0 路径。

### 3.2 非目标

- 不实现前端、后端、数据库、AI、STT、TTS、连接器、服务、部署或正式发布。
- 不把本机静态词、固定聊天回复、Mock 转写、预置统计或浏览器状态当成真实能力。
- 不增加排行榜、徽章、金币、广告、社交、付费、新闻流或复杂数据大屏。
- 不修改 13 项用户母版；新资产全部进入新版本目录。
- 不用本设计自动解冻固定 05、06、07、08 或其他角色。

## 4. 信息架构

### 4.1 一级导航

| 一级入口 | 核心任务 | 二级内容 |
|---|---|---|
| 首页 | 立即开始当天学习 | 今日计划、到期/逾期、账号与同步摘要 |
| 背单词 | 新词、到期复习、行内拼写 | Word 卡、查看答案、证据、阶段、历史 |
| 练口语 | 20 场景与自由对话 | AI 会话、文字、录音、转写确认、播放、反馈 |
| 统计 | 理解真实学习结果 | 学习量、时长、独立正确率、辅助结果、掌握与证据 |
| 设置 | 管理账号、提醒和数据 | 账号、定级、时区、同步、隐私、双导出、删除 |

服务与质量说明是设置中的次级入口，不在首页制造工程噪音。

### 4.2 核心任务流

```text
账号 / 游客
  → 定级或明确跳过
  → 首页双主入口
     ├─ 背单词 → 今日队列 → 行内槽 → 结果 → 证据 / 下次复习
     └─ 练口语 → 场景或自由对话 → 文字 / STT → AI 回复 → TTS / 反馈
  → 统计证据
  → 设置 / 同步 / 导出 / 删除
```

所有写入型操作都经过 `本地动作 → 服务端确认 → 跨端收敛`。任一环节没有证据时只显示“保存尚未确认”，不提前显示“已同步、已掌握、已导出或已删除”。

- 桌面主标题 36 / 44；页面标题 28 / 36；卡片标题 20 / 28；正文 16 / 26；辅助 14 / 22。

- 阴影仅表达浮层和层级：卡片使用柔和短阴影；不使用霓虹、玻璃拟态或发光按钮。

### 5.3 图标与动效

- 线性圆角图标；同一状态全站保持同一图标语义。
- 处理中允许静态进度与短时旋转；减少动态效果时关闭位移和循环动画。
- 成功不撒花，错误不抖动，提醒不自动轮播，语音不自动播放。

## 7. 核心组件规范

### 7.1 真相条

结构：状态图标 + 简体中文状态 + 影响说明 + `最近成功时间 / 尚无记录` + 恢复动作。

显示层级：

- 全页受影响：页面标题下全局真相条。
- 单能力受影响：放在 AI、STT、TTS、同步、导出等组件内部。
- 演示数据：贴近数字、图表或记录，不用页脚统一免责代替。

### 7.2 行内字母槽

- 整组是一个可命名输入；每个字母槽只表达位置，不制造 6 个独立 Tab 停靠点。
- 提示字母和用户输入在同一组内稳定合并；连字符、撇号、空格固定显示。
- 未填完整只提示剩余数量，不判错；错误保留输入；查看答案只在原槽只读揭晓。
- 揭晓前不把完整答案放入可见、复制或辅助文本。
- 保存超时显示“保存尚未确认”，禁止提前推进阶段或显示已掌握。

### 7.3 AI / STT / TTS 组合输入

| 能力 | 正常 | 降级 / 失败 | 永远可用的恢复路径 |
|---|---|---|---|
| AI 回复 | 流式或完整真实回复 | 未完成、限流、内容安全拒绝、服务不可用 | 保留输入和历史，显式重试；不插缓存脚本 |
| STT | 录音 → 处理 → 实际转写 → 编辑确认 | 未授权、静音、无有效音频、失败 | 文字输入始终可用 |
| TTS | 对应真实回复可播放 | 尚未就绪、播放失败、浏览器朗读降级 | 文本始终可读；不伪造播放成功 |

麦克风禁用时仍可聚焦并查看原因；正确禁用不等于不可解释的灰块。

### 7.4 同步与冲突

- 显示当前账号、设备、revision、最后成功时间、未确认动作数和来源。
- 设备 A“已查看答案”与设备 B“作答中”冲突时，保留不可逆查看证据，阶段不重复推进。
- 合并结果提供人类可读摘要和事件证据抽屉；不使用“最后页面覆盖全部状态”。
- 离线写入不结算，恢复后由用户确认重试。

### 7.5 双导出与删除

- “下载可阅读报告”和“下载机器可读数据”是两个同时可达的独立操作，不做互斥单选。
- 状态分别为：尚未就绪、准备中、可下载、已过期、失败；空文件不算成功。
- 删除确认写明登录立即失效、活动数据 24 小时、备份最长 30 天和申诉 / 重试路径。
- 没有真实删除服务时，危险按钮正确禁用并解释原因；不能展示“已删除”。

## 8. 统一状态模型

| 内部状态 | 用户可见文案 | 视觉 / 非颜色编码 | 主要恢复动作 |
|---|---|---|---|
| `loading` | 正在加载 | 进度图标 + 骨架，关键操作禁用 | 等待 / 取消 |
| `live` | 当前可用 | 对勾 + 实线边界 + 最后成功时间 | 继续任务 |
| `empty` | 暂无内容 | 空盒图标 + 原因 + 下一步 | 新建 / 返回学习 |
| `not_ready` | 尚未就绪 | 时钟图标 + 依赖说明 | 查看原因 / 稍后重试 |
| `stale` | 数据已过期 | 日历警示 + 截止时间 | 刷新 |
| `degraded` | 部分功能降级 | 斜纹 / 警示图标 + 可用替代 | 改用文字等安全路径 |
| `failed` | 本次请求失败 | 错误图标 + 请求范围 + 原因 | 重试 / 申诉 |
| `offline` | 当前离线 | 断网图标 + 禁止结算说明 | 恢复网络后确认重试 |
| `unauthorized` | 登录已失效 | 锁图标 + 缓存已清除说明 | 重新登录 |
| `forbidden` | 无权访问此数据 | 盾牌图标 + 零数据泄露 | 返回本账号 |
| `processing` | 正在处理 | 进度 + 开始时间 | 保持页面 / 查看任务 |
| `unconfirmed` | 保存尚未确认 | 琥珀警示 + 不计分说明 | 幂等重试 |
| `conflict` | 检测到跨设备冲突 | 两设备图标 + 合并摘要 | 查看详情 / 重新同步 |

`failed` 只用于真实请求已执行并失败；未接通或没有真实请求时必须使用“尚未就绪 / 不可用”。

## 9. 入口真实性与三重闭环

四项目真实可用产品增量共 41 项；本设计只承接其中 English 子集，并将其收敛为以下 14 个入口组：

| 入口组 | 界面真相 | 设计完成条件 |
|---|---|---|
| 身份 / 登录 / 退出 | 不能显示静态 Alex；访客边界明确 | A/B 切换后零可见性，失效安全退出 |
| 定级 | 没有有效作答不得给默认等级 | 版本、时间、限制与无法判定 |
| 首页计划 | 没有真实计划就显示尚未生成 | 推荐原因、词库版本、截止时间 |
| 真实词库 | 3 个硬编码词不构成词库 | 身份、许可、版本、答案完整性 |
| Word 写入 | 本地成功不等于服务端确认 | 幂等事件、revision、失败不推进 |
| 记忆队列 | 浏览器本地状态不等于跨端单一真相 | 同日 / 跨日、漏学、复发、掌握可重放 |
| 任务控制 | 无效、离线、冲突、提交中时正确禁用 | 开始 / 跳过 / 暂停 / 恢复 / 重置有原因 |
| 提醒 / 时区 | 浏览器请求不等于送达 | 真实队列、权限、免打扰、时区生效说明 |
| 20 场景 / 自由对话 | 固定回复不得冒充真实 AI | 真实上下文、限流、安全、失败和恢复 |
| STT | Mock 转写不得显示成功 | 权限、录音、真实转写、编辑确认、失败 |
| TTS / 反馈 | 固定 86 分不得出现 | 音频来源、文本证据、推断边界、播放失败 |
| 统计 | 预置数字不得冒充个人数据 | 公式、规则版本、截止时间、事件复算 |
| 同步 / 导出 / 删除 | 本地快照不等于跨设备或数据权利 | revision 收敛、双导出、撤权、备份限制 |
| 服务 / 质量 | HTTP 200 不等于业务就绪 | health / readiness 分离，来源与版本可见 |

每个入口同时满足三重闭环才可在正式界面显示“当前可用”：

1. 依赖闭环：真实服务、凭证、版本、来源与 readiness 有证据。
2. 联调闭环：成功、空、未就绪、过期、降级、失败、权限、冲突和重试均通过。
3. 产品闭环：简中、移动、键盘、读屏、时间、来源、数据权利和恢复路径完整。

## 11. 响应式与 200% 放大

### 11.1 逻辑视口

| 档位 | 逻辑视口 | 布局 |
|---|---:|---|
| 桌面 | 1440×1024 | 232px 侧栏 + 1–3 栏任务区 |
| 平板 | 1024×768 | 单阅读顺序，允许 65/35 双栏 |
| 手机 | 390×844 | 单列、底部安全区、软键盘避让 |
| 小屏手机 | 320×568 | 独立重排、按钮纵排、时间线列表化 |

### 11.2 200% 浏览器语义

- 1440 在 200% 下按 720 CSS 宽度回流；1024 按 512；390 和 320 进入更窄的单列布局。
- 不用缩放截图模拟；布局、文字、间距、圆角和焦点都按有效视口重新计算。
- 图表可先显示摘要与等价表；页面不得横向滚动。
- 标题、按钮、状态文字、错误、软键盘上方输入和危险确认均不截断、不重叠、不被固定栏遮挡。

## 12. 无障碍规范

1. 首个可聚焦元素是“跳到主内容”；焦点顺序与视觉顺序一致。
2. 触控目标至少 44×44px；键盘焦点环至少 2px，使用品牌紫与足够外间距。
3. 对话框打开后焦点进入并限制在层内；安全按钮默认聚焦；关闭后返回触发器。
4. 行内槽作为一个有名称的输入；播报上下文、总字母数、已填、提示位置、剩余和结果。
5. 揭晓前不能从辅助名称、复制内容或隐藏文本泄露答案。
6. AI / STT / TTS、同步、导出和删除状态通过 `aria-live="polite"` 或等效方式播报；身份失效和危险错误可使用紧急播报。
7. 图标按钮具有完整中文名称；内部键不作为用户可见标签。
8. 图表和等价表同源；状态同时使用文字、图标、形状或线型。
9. 录音不是唯一入口，语音失败始终保留文字。
10. 支持系统大字号、200% 放大、高对比和减少动态效果。
