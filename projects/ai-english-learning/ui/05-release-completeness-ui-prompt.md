## START OF DESIGN PROMPT

你是一名资深教育产品 UI/UX 设计师。请基于随提示词提供的 AI English Learning 权威视觉母版，为这款响应式 Web/H5 英语学习产品设计一套可以支撑正式发布验收的高保真增量界面。

这是已有产品的扩展，不是品牌重构。请保留母版的暖米色背景、青绿色强调区、品牌紫主操作、白色内容面板、柔和圆角、轻阴影、大留白和“背单词 / 练口语”双主入口。母版中的乱码、英文导航、示例头像、示例数字和统计图只代表构图与视觉语言，不代表真实文案或真实数据；新设计必须使用准确、自然、克制的简体中文。

### 1. 设计目标

1. 首页仍然极简，用户第一眼只需在“背单词”和“练口语”之间选择；账号、统计、设置和数据权利退居次级入口。
2. 新用户能完成登录或了解访客限制、进行真实可解释的 A1–C2 测级，并知道测级是否真正完成。
3. 背单词形成“今日任务 → 句中行内字母槽作答 → 薄弱词登记 → 间隔复习 → 当前掌握”的连续体验。
4. 练口语同时覆盖 20 个固定场景和自由对话；只有真实 AI 回复、真实语音识别与真实语音播放成功时才显示成功状态。
5. 用户能区分独立答对、使用提示答对、查看后答对、拼写错误、未完成与异常，不把辅助练习误算为独立掌握。
6. 统计必须可解释、可追溯、可重算；不展示无法说明来源的精确分数、记忆预测或虚构增长。
7. 跨设备状态、离线写入、冲突合并、服务未就绪、局部降级和失败均有清楚且可恢复的界面，不用“加载中”掩盖真实不可用。
8. 用户能理解数据来源、导出自己的数据并发起删除账号；删除失败和处理中不伪装完成。
9. 所有核心路径均提供 1440、1024、390、320 宽度设计，支持键盘、屏幕阅读器、200% 放大和减少动态效果。
10. 界面保持极简、干净、有逻辑，不把产品做成数据大屏、游戏关卡、社交社区或复杂后台。

### 2. 真实性与演示标识（最高优先级）

#### 2.1 设计生成阶段的强制真相条

每张含账号、测级、学习数据、AI、语音、同步、统计、导出或删除结果的设计稿，都必须在页面上就近出现以下二者之一：

- 目标态稿：`目标态演示 · 当前能力是否接通以实际服务状态为准`
- 示例内容：`演示数据 · 非真实用户记录`

标识要可见、可读，但不能压过当前任务。不得仅写在画板名称、备注层或不可见元数据里。

#### 2.2 用户可见真实性状态

界面使用完整简体中文，内部键只可在开发附注中括号保留：

| 用户文案 | 内部键 | 使用条件 | 允许的主要操作 |
|---|---|---|---|
| 可用 | `live` | 真实请求成功且数据新鲜 | 正常操作 |
| 暂无内容 | `empty` | 请求成功但确实无数据 | 返回、开始创建或稍后查看 |
| 尚未就绪 | `not_ready` | 服务、身份、词库、AI 或语音前置未接通 | 查看原因、重试或使用明确降级路径 |
| 数据可能已过期 | `stale` | 有旧数据但新鲜度超限 | 显示最后成功时间、刷新 |
| 部分功能暂不可用 | `degraded` | 主流程可继续，某个子能力不可用 | 使用文本等降级方式、重试子能力 |
| 操作失败 | `failed` | 已真实发起请求且失败 | 保留输入、重试、返回安全状态 |
| 当前离线 | `offline` | 网络不可用 | 查看本地可读内容；产生写入时明确“尚未确认” |
| 正在处理 | `processing` | 导出、删除等异步任务已受理 | 查看进度、稍后返回 |
| 保存尚未确认 | `unconfirmed` | 本地已操作但服务端未确认 | 保留草稿、重新同步 |
| 检测到数据冲突 | `conflict` | 多设备或版本产生冲突 | 查看合并结果与保留证据，不让用户二选一丢记录 |

- “尚未就绪”与“操作失败”不可混用：没有真实请求执行历史时只能是尚未就绪或不可用。
- 局部失败只降级局部区域；例如语音播放失败不应抹掉已经生成的文字回复。
- 每个服务状态显示：状态文字、最后成功时间或“尚无成功记录”、重试入口、可用降级路径。
- 不把 HTTP 成功、按钮可点击、静态示例或缓存脚本称为真实 AI、真实语音、真实同步或正式发布完成。

### 3. 主要用户与核心场景

- 首次使用者：注册或登录，了解访客边界，完成测级后进入清楚的学习起点。
- 手机学习者：通勤中单手背单词、查看今日复习、进行短口语对话，软键盘不遮挡主操作。
- 桌面学习者：使用键盘连续完成单词题、浏览学习记录、长对话和统计详情。
- 多设备学习者：手机和电脑之间继续同一账号进度，并看懂待同步、已同步或冲突状态。
- 使用辅助技术的学习者：不依赖颜色、拖动、长按、悬停或语音即可完成核心任务。
- 注重隐私的学习者：清楚知道保存什么，能导出并删除账号与数据。

### 4. 信息架构

#### 4.1 一级导航

1. 首页
2. 背单词
3. 练口语
4. 学习统计
5. 设置与账号

移动端首页只突出“背单词 / 练口语”两个主入口；统计和设置放在头像、底部次级导航或菜单中。桌面端可沿用左侧栏，但不得让侧栏比双入口更抢眼。

#### 4.2 二级结构

- 背单词：今日任务、普通学习、待复习队列、作答、单题结果、学习项详情、提醒设置。
- 练口语：场景目录、场景详情、自由对话、会话、逐轮反馈、语音与文本降级。
- 学习统计：学习概览、独立正确率、辅助与查看次数、复习到期、口语活动、可追溯明细。
- 设置与账号：个人资料、账号切换、学习偏好、提醒、同步状态、数据说明、导出、删除账号、退出登录。
- 系统辅助页：登录恢复、测级、服务状态、冲突说明、导出任务、删除任务。

#### 4.3 核心流程

1. 未登录 → 登录 / 注册 / 访客说明 → 测级 → 首页。
2. 首页 → 背单词 → 今日任务 → 行内字母槽作答 → 结果 → 下一题 / 复习安排。
3. 首页 → 练口语 → 20 场景或自由对话 → 文字/语音输入 → 真实 AI 回复 → 逐轮反馈 → 会话总结。
4. 首页或设置 → 学习统计 → 指标说明 → 对应证据明细。
5. 设置 → 同步与数据 → 导出数据 / 删除账号 → 处理状态 → 完成或失败恢复。

### 5. 关键页面与页面要求

#### 页面 01：未登录、登录与访客边界

- 单卡极简登录页：品牌、价值说明、账号输入、继续、访客体验入口。
- 访客入口旁直接写明：`访客进度仅保存在当前设备，无法跨设备同步或恢复。`
- 登录中禁用重复提交并保留输入；失败时显示具体可恢复原因，不清空账号。
- 登录态失效：`登录已过期，请重新登录。未同步的本地记录仍会保留。`
- 多账号切换必须显式显示当前账号名称或掩码标识；切换确认说明“不会把 A 账号数据带入 B 账号”。
- 提供登录、退出、A/B 账号切换、账号间零可见性和访客升级的状态稿。

#### 页面 02：A1–C2 初始测级

- 开始页说明预计题量、可中断恢复、用途和版本：`测级版本 vX · 结果用于生成起始学习范围。`
- 作答页保持单题聚焦，显示进度但不显示虚构实时能力分。
- 完成页显示等级、测级时间、版本、简短能力描述和限制说明；主操作为`开始学习`。
- 中断后可继续；版本不兼容时说明需要重新测级。
- 题目不足、服务未就绪、提交失败均显示`测级未完成，暂时无法判定等级`，绝不默认给等级。
- 结果为目标态示例时就近标`演示数据`。

#### 页面 03：首页与今日任务

- 保持两个大入口：`背单词`、`练口语`。
- 顶部只展示当前账号和设置入口；底部可显示一句真实今日摘要。
- “背单词”入口可显示紧凑徽标：`8 个今日复习`；“练口语”可显示`继续上次对话`，没有数据时不占位造数字。
- 今日任务说明为什么出现：新词、今日到期、逾期、今日加固；默认只展示简短原因，详情按需展开。
- 首页不放新闻流、排行榜、积分商城、复杂图表或多层卡片。

#### 页面 04：单词学习中心与待复习队列

- 继承 v1.3：今日复习、逾期、今日到期、今日加固、普通新词的真实分组与优先级。
- 队列卡显示单词、目标含义、阶段、出现原因、到期状态和主要操作；列表不提前泄露答案。
- 超过每日 20 个到期项时显示`今天先复习 20 个，另有 N 个仍处于逾期`。
- 空队列：`今天没有到期复习，可以学习新单词。`
- 离线、题库缺失、非法到期、提醒权限、跳过、暂停、恢复和重置状态完整。

#### 页面 05：单词作答与查看答案

- 英文句子中的缺词位置是唯一答案输入和答案展示位置，禁止恢复句子下方独立输入框。
- 整组字母槽在语义上是一个文本输入；支持连续输入、点击定位、方向键、退格、替换、完整答案粘贴和剩余字母粘贴。
- 系统提示字母、用户输入、空槽、固定连字符/撇号/空格和当前编辑位必须有非颜色区分。
- 未完成提交只提示`还差 N 个字母`，不判错；答错保留原输入并允许原位修正。
- “查看答案”低强调但可发现。首次触发先确认；确认后只在原槽展示标准答案并只读，不增加句下答案框。
- 揭晓后显示`正确答案 · 已查看`、`本题不计独立答对`，主操作`下一题`，次操作`重新作答本题`。
- 查看后重试答对仍标`辅助练习答对`，不回填独立正确率或熟练度收益。
- 复习题如使用提示，立即显示`已使用提示 · 本次不推进掌握阶段`。

#### 页面 06：薄弱词、间隔复习与单题结果

- 继承阶段：薄弱待加固 → 次日回忆 → 短期间隔 → 周期检查 → 掌握检查 → 达到当前掌握标准 → 30 天维护。
- 用自然日期呈现 D+1、D+3、D+7、D+14、D+30；不显示虚构记忆率或“永久掌握”。
- 结果明确区分：独立拼写正确、辅助练习答对、查看后练习答对、拼写错误、同日加固答对、达到当前掌握标准、维护完成、维护后重新巩固。
- 历史时间线保留原始日期、时区、是否使用提示/答案、阶段变化和下一安排。
- 查看答案和完整拼写错误登记薄弱证据；未完成提交和取消查看确认不登记。

#### 页面 07：口语场景目录

- 提供 20 个可识别、可搜索或按主题筛选的固定场景，至少显示场景名、目标、难度和完成状态。
- 自由对话作为独立入口，明确`自由选择话题，与 AI 连续对话`。
- 场景资源缺失只让对应场景不可用，不应让全部口语入口消失。
- 未接入真实 AI 时显示`口语服务尚未就绪`，不展示可发送但只会返回静态脚本的假输入框。
- 场景完成状态只基于真实会话记录；示例状态标`演示数据`。

#### 页面 08：真实 AI 口语会话

- 会话结构：场景/话题标题、轮次记录、对方消息、用户消息、输入区、麦克风、发送、语音播放和逐轮反馈入口。
- 自由对话至少支持 3 轮连续上下文；界面通过主题标题和轻量上下文摘要帮助理解，不堆完整系统提示词。
- 发送后依次表达：正在发送、AI 正在回复、回复成功、局部反馈生成中、局部失败。
- 只有真实新回复成功才新增 AI 气泡；不得在失败时插入缓存脚本并伪装为本轮回复。
- 用户原输入始终保留；重试不可重复生成两条用户消息。
- AI 回复、纠错建议、发音反馈和词汇扩展分层展示，不混成一段大文字。

#### 页面 09：语音识别、播放与降级

- 麦克风状态：未授权、请求权限、录音中、处理中、识别成功、未识别到语音、权限拒绝、设备不支持、识别失败。
- 录音中有明确停止按钮、时间提示和文本状态；不只靠波形颜色。
- 识别结果先让用户确认或编辑，再发送；未经确认不得把误识别内容自动发给 AI。
- 语音播放状态：可播放、加载中、播放中、播放失败、不可用。
- 语音不可用时保留文字对话，显示`语音暂不可用，你仍可输入文字继续练习。`
- AI 全部不可用时保留未发送草稿，显示重试和退出；不得把本地预置内容当新 AI 回复。
- 音频保存和最小化说明放在数据说明页，不在会话主区堆隐私长文。

#### 页面 10：学习统计与证据明细

- 概览指标：学习天数、学习时长、独立答对、使用提示答对、查看答案、已掌握、今日到期/逾期、口语会话与轮次。
- “独立拼写正确率”必须提供口径：分子只含无提示、未看答案的完整独立答对；辅助、查看后答对不进入分子。
- 每个指标可进入证据明细，显示时间范围、最近更新时间、数据来源和可重算记录数量。
- 统计核验中显示`数据正在核验，暂不展示最终数值`；局部统计失败只降级对应卡片。
- 不展示不可重算的学习能力总分、AI 记忆预测、同业排名或虚构百分位。

- 每张图必须有标题、时间范围、单位、图例、数据新鲜度、空态、失败态和完整等价表格。
- 若设计稿使用示例数字，图表卡就近标`演示数据 · 非真实用户记录`。
- 颜色不是唯一编码；线型、点型、图标、标签和表格共同表达。

#### 页面 11：跨设备同步与冲突

- 设置中提供紧凑状态：`已同步`、`正在同步`、`保存尚未确认`、`当前离线`、`检测到数据冲突`。
- 显示最后成功同步时间和当前账号，不承诺后台永久实时。
- 跨设备目标状态说明：同一账号的新记录应在 10 秒内收敛；设计稿必须标注这是目标态，而不是当前已实现事实。
- 冲突页不得让用户在两个版本中简单二选一而丢失查看答案、拼写错误等不可逆证据。
- 推荐展示合并摘要：保留了哪些记录、时间、设备、冲突原因、最终下一到期日；可展开技术细节但默认简洁。
- 同步失败不回滚用户已完成的本地可见操作，但必须保留`尚未确认`状态直到服务端确认。

#### 页面 12：数据说明、导出与删除账号

- 数据说明用分组列表回答：保存什么、为什么保存、保存多久、谁能看到、语音如何处理、如何导出与删除。
- 导出必须同时提供两个独立操作：`下载机器可读数据`和`下载可阅读报告`；不得设计成互斥单选。
- 导出状态：未开始、准备中、部分失败、可下载、链接过期、失败重试；显示生成时间和文件范围。
- 删除账号使用危险操作区和二次确认；说明删除影响、当前账号、退出结果和恢复边界。
- 删除提交后显示`正在删除账号`和任务状态；只有真实完成才显示`账号及活跃数据已删除`。
- 活跃数据目标 24 小时内删除、备份最长 30 天清理均需以清楚而不夸大的说明呈现；失败时保留任务编号/时间和重试或联系支持入口。
- A/B 账号切换时，导出与删除只作用于当前明确显示的账号。

#### 页面 13：服务与质量说明

- 这是次级辅助页，不放在首页主导航显著位置。
- 分别显示：身份服务、测级、词库、学习记录、AI 对话、语音识别、语音播放、统计、导出、删除。
- 每项展示可用性状态、最后成功时间或`尚无成功记录`、影响范围、降级路径和重试。
- 区分健康与就绪：`服务可访问`不等于`当前功能已具备完整数据与依赖`。
- 质量说明列出当前词库版本、测级版本、统计最近核验时间、服务数据截止时间；没有值时写`尚未提供`，不填示例冒充事实。

### 6. 关键组件与交互规范

#### 6.1 状态条与状态标签

- 结构：图标 + 简体中文状态 + 一句影响说明 + 时间/来源 + 操作。
- 成功、提醒、错误、离线、未就绪和处理中使用不同图标与形态，不能只变颜色。
- 全局状态条只用于真正影响全页的事项；局部服务问题放在局部组件内。

#### 6.2 主次操作

- 每个页面最多一个品牌紫主操作。
- 次操作使用中性描边或文字按钮；危险操作与主学习流视觉隔离。
- 加载中防重复点击；失败后恢复可操作且保留输入。
- 按钮文案使用动作结果，如`重新同步`、`确认并发送`、`下载机器可读数据`，不用含糊的`确定`。

#### 6.3 对话、抽屉与确认层

- 登录恢复、查看答案、切换账号、测级退出、重置进度和删除账号使用各自明确语义，不复用一段万能警告。
- 安全操作默认聚焦；关闭后焦点返回触发器。
- 320px 下按钮纵向排列；对话框不超出视口、不被软键盘遮挡。

#### 6.4 表格、时间线与证据

- 默认展示摘要，详细证据按需展开，避免页面大段文字。
- 表格在移动端转换为可读卡片或分组列表，不横向裁掉字段。
- 时间、版本、时区、来源和状态具有明确标签，不用裸英文键。

### 7. 视觉方向

#### 7.1 继承母版

- 暖米色页面背景，青绿色用于学习环境和新鲜行动，品牌紫用于主操作与重点状态，白色/暖白面板承载内容。

- 头像、装饰几何和统计图只在不影响任务时使用；母版中的人物仅作裁切与尺寸参考。
- 桌面保留左侧导航与居中主内容；移动端保持单列、大触控目标和底部安全区。

### 8. 响应式要求

#### 8.1 手机 320 / 390

- 分别独立重排 320 和 390，不得把 390 整体缩小到 320。
- 单列、左右安全边距至少 16px、正文至少 16px、辅助文字至少 14px、触控至少 44px。
- 首页两个主入口纵向排列；统计摘要最多一行，不在首屏增加第三个主任务。
- 软键盘打开时，当前行内槽、对话输入、反馈和主按钮可见或通过最小滚动可达。
- 统计图默认显示简化图形和摘要，完整等价表折叠展开；页面不得横向滚动。
- 同步、导出、删除和服务状态使用短卡片；长版本号、邮箱和任务号允许换行且可复制。

#### 8.2 平板 / 1024

- 保持单一阅读顺序，可用 2 栏展示摘要与详情，但不得把右栏做成不可到达的附属信息。
- 横竖屏切换不丢失输入、测级进度、对话草稿、录音确认、查看答案确认或设置草稿。

#### 8.3 桌面 / 1440

- 左侧导航 220–256px；主内容建议 720–1040px，复杂统计页最大不超过 1180px。
- 单词作答和口语会话仍是任务中心，不用空白处填满无关卡片。
- 会话页可使用“会话列表 / 对话 / 反馈”三栏，但窄桌面自动收为二栏或抽屉。

#### 8.4 200% 放大

- 按浏览器 200% 语义验证：有效 CSS 视口减半后重新回流，不是简单放大截图。
- 320、390、1024、1440 的核心内容在 200% 下无横向滚动、无文字截断、无按钮/状态重叠、无焦点遮挡。
- 图表可转为纵向等价表；关键操作和状态说明不得因放大被隐藏。

### 9. 无障碍要求

1. 所有核心操作有完整简体中文名称；图标按钮必须有可见文字或准确的辅助名称。
2. 焦点顺序与视觉顺序一致；跳过链接可直接进入主内容。
3. 对话框打开后焦点进入并限制在层内，关闭后回到触发器；安全按钮默认聚焦。
4. 状态变化使用礼貌播报；登录失效、测级未完成、AI/语音失败、同步冲突、导出和删除结果必须被读屏获知。
5. 行内字母槽作为一个有名称的输入控件；揭晓前不在可见或辅助内容中泄露标准答案。
6. 录音不能是完成口语任务的唯一方式；始终提供文字输入降级。
7. 图表提供同数据模型生成的完整等价表，图形与表格的记录、数值和状态一一对应。
8. 状态不只依赖颜色，必须结合文字、图标、线型、边界或纹理。
9. 支持键盘完成登录、测级、背词、粘贴答案、查看答案确认、口语文本会话、统计筛选、账号切换、导出和删除。
10. 支持 `prefers-reduced-motion`；无必要抖动、呼吸、倒计时或自动播放语音。
11. 日期、时间、时区、版本和新鲜度用可读文本表达，内部键不裸露给用户。
12. 长单词、中英文混排、长邮箱、长任务号和系统大字号均不得遮挡操作。
