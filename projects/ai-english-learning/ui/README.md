**版本**：v1.0 MVP

## 设计规范
### 配色
- 主色：#3b82f6 柔和蓝色
- 成功色：#10b981 绿色
- 警告色：#f59e0b 橙色
- 错误色：#ef4444 红色
- 背景：#ffffff 纯白
- 卡片背景：#ffffff 白卡片+柔和阴影
- 主文字：#1e293b 深灰
- 辅助文字：#64748b 中灰

### 字体
- 英文：Inter
- 中文：系统无衬线字体
- 大标题：24px 加粗
- 页面标题：20px 加粗
- 正文：16px
- 辅助文字：14px
- 小字：12px

### 组件规范
- 按钮圆角：16px 大圆角
- 卡片圆角：16px
- 输入框圆角：12px
- 阴影：0 4px 20px rgba(0,0,0,0.08) 柔和阴影
- 所有间距都是8的倍数
