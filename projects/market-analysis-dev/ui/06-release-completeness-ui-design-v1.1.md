## 4. 视觉系统与对比度

### 4.1 Token

| 角色 | HEX | 白底对比度 | 使用 |
|---|---:|---:|---|
| `text` | `#17212B` | 16.29:1 | 标题、正文 |
| `muted / unknown` | `#475467` | 7.69:1 | 次正文、未知标签文字 |
| `action` | `#0B6B63` | 6.37:1 | 主操作、公共事实 |
| `info` | `#1D4ED8` | 6.70:1 | 信息、焦点环 |
| `success` | `#067647` | 5.69:1 | 成功、外部核验 |
| `warning` | `#8A4B08` | 6.79:1 | 待确认、过期、目标态 |
| `danger` | `#B4233C` | 6.47:1 | 错误、冲突、删除 |
| `inference` | `#5B4BC4` | 6.46:1 | 系统推断 |

对比度由 `verify-assets.mjs` 使用 WCAG relative luminance 公式复算；全部普通文字颜色在白底 ≥4.5:1。焦点环 `#1D4ED8` 3px，外留 2px；关键图形边界目标 ≥3:1。

### 4.2 版式

- 背景 `#F6F8FA`，表面 `#FFFFFF`，边框 `#D0D7DE`；不使用卡片墙、玻璃拟态或霓虹。
- 桌面正文 14–16 CSS px；移动正文不低于 16 CSS px；H1/H2/H3 为 28/20/16。
- 间距 4/8/12/16/24/32/48；圆角 8/10/12；阴影只用于浮层。
- 动效 150–220ms，支持减少动效；加载不能只依赖旋转图标。
- 非颜色编码：实心圆=公共事实、引号=来源观点、虚线菱形=系统推断、空心圆=未知、文档=用户提供、勾印=用户确认、盾牌=外部核验、双箭头=冲突、斜纹=演示。

## 6. 真相态系统

用户可见名称必须在内部键之前出现：

| 简中状态 | 内部键 | 当前/目标边界 |
|---|---|---|
| 当前来源快照可用 | `live` | 只在目标态演示出现；当前未接通 |
| 当前条件下 0 条 | `empty` | 不是市场需求为 0 |
| 数据尚未就绪 | `not_ready` | 当前缺服务/来源 |
| 数据可能过期 | `stale` | 显示 24/48h、最近成功、失败原因 |
| 使用上一已核验版本 | `degraded` | 不冒充当前成功 |
| 部分步骤成功 | `partial` | 成功/失败项和影响范围分列 |
| 当前无可用结果 | `failed` | 保留输入并给重试/返回 |
| 当前离线 | `offline` | 本地可读不等于已同步 |
| 演示数据 | `seed_demo` | 不代表真实来源或用户 |
| 尚无可执行来源 | `no-source` | 当前 connector 0 |
| 暂无个人证据 | `no-evidence` | 未知，只提供补证据入口 |

## 8. 工作台、关系与未知路线契约

### 8.1 输入

- 1–100,000 Unicode；空白、URL-only、接近上限、超限均字段级说明；超限不截断。
- 保存模式为互斥选项：仅本次处理（默认）/ 保存到私有档案。
- 来源渠道和内容类型是两个独立维度，均可包含多属性；确认前不永久合并。
- 敏感信息只显示类别和大致位置，不回显完整值；第三方处理未授权时发送次数为 0。

### 8.2 研究关系

每条候选只能在新增证据、相互印证、重复、冲突、证据不足、不适用中互斥选择一种。不同候选可选择不同关系；“多属性”只适用于双轴分类，不适用于单条研究关系。

### 8.3 差距与路线

- 三项必要输入：已确认目标方向/层级、当前公共要求版本、用户确认或可核验证据。
- 任一缺失：显示未知、待补项、补证据/确认目标/查看版本，不显示路线、优先级或分数。
- 只有三项齐全时才进入目标态路线草案；每步包含能力、证据产物、完成判定、投入区间、依赖、来源和复评条件，并标系统推断。

## 10. 无障碍与组件状态

- 目标为 WCAG 2.2 AA，未声明已完成正式审计。
- 每页唯一 H1；标题层级连续；提供跳到主要内容。
- 方向、能力、筛选、表格、工作台、关系确认、证据、路线、历史、同步、导出和删除全部可键盘到达。

- 处理、保存、同步、重算、导出、删除和恢复用礼貌 live region 按阶段播报。
- 组件覆盖默认、悬停、焦点、按下、选中、禁用、加载、成功、待确认、警告、错误和危险。
