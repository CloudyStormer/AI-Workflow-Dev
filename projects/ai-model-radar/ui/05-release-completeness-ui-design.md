## 1. 设计结论

本轮形成一套极简、干净、内容优先、可响应式实现的发布完整性设计基线。设计把“数据是否真实可用”置于所有业务内容之前，以统一真相栏持续显示数据模式、`as_of`、最近成功、运行来源和新鲜度；再通过今日、全部事件、趋势与版本、开源/发布、事件详情、来源与连接、质量与覆盖、刷新运行详情完成开发者判断链路。

当前事实不随视觉示例改变：来源 allowlist/registry 仅完成 research-only 审批，真实运行时来源、真实连接器和已证明的 live 快照仍均为 `0`。因此当前默认页必须是 `not_ready`，不能展示假事件榜或假趋势。视觉稿中的事件、数量、时间、组织和图表均为 **界面演示数据 / 目标状态方案**，不构成新闻、运行证据、连接器启用或开发完成声明。

## 3. 信息架构

### 3.1 一级导航

1. 今日雷达
2. 全部事件
3. 趋势与版本
4. 开源/发布
5. 来源与连接
6. 质量说明

事件详情和刷新运行详情属于上下文二级页，通过来源页、事件页或真相栏进入，返回时恢复搜索、筛选、排序、分页、滚动位置、数据模式和快照身份。

### 3.2 全局页面骨架

- 桌面：左侧 72px 图标栏 + 176px 文字导航 + 顶部数据真相栏 + 主内容区。
- 平板：56px 折叠导航 + 顶部真相栏 + 双列或单列内容。
- 移动：顶部标题/真相摘要 + 单列内容 + 底部主导航；次级功能进入抽屉或“更多”。
- 320px：单列定义卡替代复杂表格，不横向滚动，不隐藏真相状态和 P0 操作。

### 3.3 全局真相栏

固定字段顺序：

1. 数据模式：`LIVE / 演示数据 / 未连接`；
2. `as_of` 与 Asia/Shanghai；
3. 最近成功刷新；
4. 运行来源数 / allowlist 数；
5. 正式事件数；
6. 新鲜度：新鲜、可能过期、最近可用；
7. 故障范围入口。

任何路由不得隐藏数据模式。`seed_demo` 使用独立快照身份、独立指标和独立刷新历史，不得与 live 混合。

## 4. 设计系统

### 4.1 颜色

| Token | 色值 | 用途 |
|---|---|---|
| `canvas` | `#F5F7FA` | 页面背景 |
| `surface` | `#FFFFFF` | 卡片、面板、抽屉 |
| `primary` | `#312E81` | 主导航、主动作、关键选中 |
| `secondary` | `#0F8F87` | 可信辅助、开放语义、完成 |
| `info` | `#2563EB` | 信息、链接、焦点辅助 |
| `warning` | `#B7791F` | 陈旧、降级、条件缺失 |
| `danger` | `#C2414B` | 失败、阻断、撤回 |
| `text-primary` | `#172033` | 正文与标题 |
| `text-secondary` | `#5F6B7A` | 辅助说明 |
| `border` | `#DDE3EA` | 分割线、卡片边界 |

状态永远使用文字 + 图标 + 形状，颜色只作为增强。

### 4.2 字体与排版

- 字体：`PingFang SC, Source Han Sans SC, Inter, sans-serif`。
- 等宽：版本、tag、commit、时间、任务 ID 使用系统等宽特征。
- 页面标题：32/40，600；移动 24/32，600。
- 区块标题：20/28，600；卡片标题 16/24，600。
- 正文：14/22 或 16/24；辅助文字 12/18，不小于 12px。
- 长版本号、URL、commit 可换行、复制、展开，保留完整值。

### 4.3 尺寸、间距与层级

- 基础间距：4、8、12、16、24、32、40、48px。
- 卡片圆角 12px；输入、按钮、标签 8px；状态胶囊 999px。
- 控件最小高度：桌面 36px，触摸设备 44px。
- 卡片默认 1px 边框；仅浮层使用 `0 8px 24px rgba(23,32,51,.12)`。
- 单屏最多一个主强调区，避免同级卡片铺满。

### 4.4 动效

- 普通过渡 160ms，浮层 220ms，`cubic-bezier(.2,.8,.2,1)`。
- 状态变化不闪烁、不自动滚动；刷新只更新必要区域。
- `prefers-reduced-motion` 下移除位移和循环动画，仅保留即时透明度变化。

## 5. 页面与交互

### 5.1 今日雷达

当前默认 `not_ready`：

- 标题“未连接真实来源”；
- 说明“来源研究已批准，但运行时来源为 0”；
- 次级状态“尚无真实运行证据”；
- 只提供“查看来源研究”和“切换演示数据”；
- 不显示假空榜、假事件卡、假趋势或“实时采集中”。

目标 live 方案：真相栏 → 4 个关键指标 → 事件类型趋势 → 0–20 条重点事件 → 日报/遗漏窗口。所有画板必须标“目标状态方案 · 界面演示数据”。

降级方案：琥珀横幅“部分来源失败”，显示最近成功快照、失败范围、数据时效和受影响来源；旧快照继续可读，不混入演示数据。

### 5.2 全部事件

- 搜索覆盖组织、对象、标题、摘要、版本、tag、commit。
- 筛选覆盖时间、地区、对象、事件类型、开放语义、许可证、事实标签、置信度、开发者动作、政策状态、运行状态、新鲜度和已读。
- 始终显示结果数、已生效条件和“清除全部”。
- 桌面可切换紧凑表格/卡片；移动只用卡片。
- 返回保持快照、条件、排序、分页和滚动位置。
- 明确区分全局空、筛选空、无快照、未就绪、失败和权限阻断。

### 5.3 趋势与版本

- 固定 7/30/90 日；标题只能为“本雷达已接入来源样本趋势”。
- 图表邻近显示样本 N、运行来源/allowlist、覆盖、缺失天、规则版本、`as_of`、已知缺口和“查看等价表格”。
- 规则或覆盖变化以断点标记不可比区间。
- runtime=0 时仅显示 `not_ready` 与指标定义，不绘制假趋势。
- 版本时间线覆盖模型、API、SDK、CLI、Agent 和框架的发布、更新、breaking、deprecation、回滚和生效。

### 5.4 开源/发布

- 卡片突出身份、版本/tag/commit、开放语义、许可证、发布时间、生效/弃用、主源、证据角色和开发者动作。
- `open-source / open-weights / source-available / 待核验` 独立表达。
- 公开仓库、Star、普通 commit、客户端 Release 不自动等于模型正式发布。

### 5.5 事件详情

固定顺序：发生了什么 → 为什么重要 → 开发者动作 → 适用对象/依据/截止 → 关键事实 → 完整时间契约 → 证据链 → 修正/撤回历史 → 原文外链。

事实标签为“已确认事实、来源观点、独立验证、系统推断、待核验”。置信度和重要性分开。厂商无独立证据的性能主张必须写“厂商称，尚无独立验证”。

### 5.6 来源与连接

- 顶部固定“政策研究不等于运行接入”。
- 政策轴：`allow / conditional / manual_only / disabled`。
- Runtime 轴：未配置、未运行、正常、延迟、降级、失败。
- 当前默认显示“当前运行时来源：0”“真实连接器：0”。
- 页面仅允许查看来源研究、条件和失败原因；本轮不提供启用、配置、绕过或重试风暴入口。
- 320px 将矩阵转为分组定义卡，仍能筛选政策和运行状态。

### 5.7 质量与覆盖

- 展示候选、隔离、主源匹配、核验、去重、正式事件、修正/撤回、覆盖、缺失天、规则版本、快照年龄和影子运行。
- 未实测时固定“尚无真实运行证据”，数量可为 0，不显示假转化率。
- 健康、就绪、调度、连接器、快照和内容质量分别表达。

### 5.8 刷新运行详情

- 状态：等待、进行中、共用既有任务、部分成功、完成、失败、取消、遗漏计划窗口。
- 显示任务 ID、触发方式、计划/开始/结束、来源结果、新增/更新/合并/隔离和快照。
- 刷新时继续阅读旧快照；新快照可用后由用户主动切换。
- 部分失败保留成功结果；全部失败保留旧 live；无旧 live 则 `not_ready`。
- 不自动回退或混入演示数据。

## 6. 图表规范

| 图表 | 映射 | 必备说明 |
|---|---|---|
| 事件趋势折线/面积 | X=Asia/Shanghai 日期；Y=正式事件数；系列=类型 | 断点、样本、等价表 |
| 来源覆盖堆叠条 | X=日期；Y=有效来源数；堆叠=来源类型 | 社区线索不计主源 |
| 地区×来源矩阵 | 行=中国/全球；列=来源类型；值=正式样本 | 文字/图案编码 |
| 版本演进时间线 | X=时间；Y=对象；节点=发布/弃用等 | 键盘可聚焦 |
| 开放语义条形 | 分类=开放语义；值=正式事件数 | 许可证缺失另标 |
| 候选晋级漏斗 | 候选→主源→核验→去重→正式 | 未实测不显示转化率 |
| 政策×Runtime 矩阵 | 行=政策；列=运行状态；值=端点数 | 双轴不可合并 |
| 来源运行热力格 | 来源×运行窗口 | 等价表与文字状态 |
| 快照新鲜度带 | 0–24h、24–48h、>48h | 显示 `as_of` 与遗漏窗口 |

禁止市场份额饼图、3D、装饰仪表、无基线百分比和仅靠颜色的热力图。

## 7. 64 状态分组

1. 数据模式与加载：当前未就绪、LIVE 正常、降级 LIVE、演示数据、初次加载、后台刷新、加载超时、真空榜。
2. 空态与故障：筛选无结果、无快照、无运行来源、单源失败、部分失败、全部失败·有旧快照、全部失败·无旧快照、离线。
3. 时间与新鲜度：服务中断、24 小时内、超过 24 小时、超过 48 小时、今天、过去 24 小时、补录、未来时间隔离。
4. 事实与证据：时区错误、时间顺序冲突、已确认事实、来源观点、独立验证、系统推断、待核验、无主源。
5. 开放语义与变更：证据冲突、撤回、修正、跨站合并、版本不同不合并、open-source、open-weights、source-available。
6. 刷新任务：许可证未声明、breaking、deprecation、价格/限额、安全/服务紧急、监管影响、刷新等待、刷新进行中。
7. 来源政策与运行时：共用任务、部分成功、新快照可用、allow·未配置、conditional·条件缺失、manual_only、disabled、政策允许·运行失败。
8. 趋势/偏好/安全：政策过期阻断、登录/付费阻断、趋势无样本、趋势缺失天、趋势断点、偏好仅本浏览器、外链身份不匹配、不可信正文。

每个状态必须定义状态名称、辅助文案、主要动作、禁用逻辑、进入焦点和读屏播报；业务页面只使用相关状态，完整矩阵放在组件板。

## 8. 响应式

### 1440px

- 12 栏内容网格；主内容最大宽度 1440px。
- 来源矩阵、趋势、证据链和刷新结果可使用表格。
- 筛选和排序同屏，二级详情支持左右分区。

### 1024px

- 导航折叠为图标栏；4–8 栏自适应。
- 趋势元数据换成两行；表格保留最关键列，其余进入展开详情。

### 390px

- 单栏、底部主导航、全屏筛选抽屉。
- 卡片信息顺序为真相 → 标题/对象 → 事实 → 动作 → 证据。
- 详情使用折叠区，但核心事实和开发者动作默认展开。

### 320px

- 不横向滚动；来源矩阵转定义卡；趋势先结论后图表，再等价表入口。
- 筛选抽屉完整保留选项和已选数量。
- 长版本、URL、commit 逐字符换行并支持复制。

### 200% 缩放

导航、真相栏、标题、筛选和操作不重叠；内容重排为单列，功能不丢失。

## 9. 无障碍

- 所有 P0 路径仅用键盘可完成；首个入口为“跳过导航”。
- 焦点顺序与视觉顺序一致；焦点环 2px，颜色对比不低于 3:1。
- 弹层打开时焦点进入标题或首个安全操作，关闭后回到触发点。
- 刷新、筛选结果、错误、过期、模式变化使用适度 `aria-live`。
- 每张图提供一句结论、等价数据表和键盘可聚焦数据点。
- 状态使用文字 + 图标 + 形状；正文对比度满足 WCAG 2.2 AA。
- 触摸目标至少 44×44px；关键内容不依赖 hover。
- 外链读出目的、域名和新标签页行为。
- 动效遵守 `prefers-reduced-motion`。

## 10. 设计与实现边界

- 本轮只完成设计说明和视觉稿，没有修改前端、后端、架构或任务拆解。
- 没有实现或启用连接器、runtime、采集、数据库、调度、影子运行或部署。
- 设计图中的示例事件、来源和数字不进入生产数据，也不能作为验收证据。
- 旧 `ui/03-ui-prompt.md`、9 张历史图片、旧 `ui-design-review` 和冻结的 `artifact-radar-frontend-001/frontend-delivery-review` 均保留。
- 本设计未获批准前，不授权架构、开发或其他项目 UI。
