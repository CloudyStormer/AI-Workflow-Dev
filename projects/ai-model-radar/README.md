# AI Model Radar

用于验证 AI 工作流的“大模型动态雷达”实验项目。

目标是把国内外大模型的重要动态汇聚到一个界面：定时或按需刷新、跨来源去重、按重要性排序，并给超级无敌帅超超总展示每日约 10–20 条值得关注的进展。信息必须回链到原始来源，区分事实、来源观点和系统摘要。

当前已完成并批准市场调研，项目计划 v1.0 已交付待审核。PRD、UI 提示词、架构、开发、测试和发布必须按根目录 `skill/ai-dev-workflow/SKILL.md` 的一跳审批门逐步推进；明确“通过”会自动启动唯一下一站，无需再等“继续”，但不会跑完整链路。

## 统一结构

本项目已由 `workflow-project-init` 收编：

- `project.yaml` 声明项目身份、`split-web` Profile、模块和入口。
- `skills/project-ai-model-radar/SKILL.md` 是项目级 Skill。
- `skills/` 中其他 Skill 是项目级 Skill 调用的专业子 Skill。
- `workflow/` 保存状态、审批、产物、事件和 Skill 锁。
- `docs/` 保存需求与调研证据。
- `frontend/`、`backend/`、`docker/` 只是预留实现目录；技术栈尚未批准。

治理外壳与另外两个项目一致；尚未实现代码，所以没有伪造启动、构建或测试命令。
