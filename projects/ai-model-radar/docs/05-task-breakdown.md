## 1. 管理结论

首批实施只覆盖 **MVP-1 静态演示快照驱动的完整简体中文 Web**。任务顺序保证第一项就产生可在浏览器查看的中文页面，随后再补齐数据契约、领域规则、六类页面、36 项状态、响应式、无障碍与真实性质量门。

## 4. 本批完成定义与排除项

### 4.1 完整浏览内容候选

只有完成 `AMR-FE-001` 至 `AMR-FE-031` 并通过相应审核，才可称为“首批完整可浏览内容候选”，且必须同时满足：

- 默认进入 `/today`，六类页面可在无后端、无账号、无第三方网络时浏览；
- 每个页面持续显示“演示数据 · 人工快照 · 截至时间 · 未连接自动采集服务”；
- 日榜 0–20 条、普通单厂商上限、紧急事件、主源硬门、事实标签、证据根和版本化排序由确定性规则实现；
- 已发布快照不可原地覆盖；当前版损坏时只可回退到 Manifest 明确指向且校验通过的上一版，并显示真实 `as_of`，否则失败关闭；
- 来源目录明确是截至 2026-07-31 的研究核验快照，不等于已接入运行；
- 偏好、已读、收藏和反馈只存在于当前标签页内存态，不声称账号、云端或跨设备；
- 质量指标当前值只能是“未实测”，未来部分成功、失败等界面必须标注为后续服务状态示意；
- 完整简体中文版覆盖导航、操作、状态、图表标签、错误、空状态、无障碍文案和移动端；
- PRD `AC-01..AC-42` 均被明确映射为“本批实现验证／未来服务 UI 契约示意／后置运行验证”，不得把契约示意或未来门槛写成当前已通过；
- UI Prompt 36 项页面状态和组件 Default／Hover／Focus／Active／Disabled／Loading／Error／只读矩阵均有当前实现或明确标注的未来示意，并有可追溯检查证据；
- 9 张批准视觉基线逐项完成“视觉遵循／真实性修正／不适用”映射；桌面与移动最近两个主要版本只按实际可用环境报告；

`AMR-FE-001` 只表示首条中文可见纵切，不代表六类页面、36 状态或整个 MVP-1 已完成；`AC-31`、`AC-41`、`AC-42` 等后端／影子运行语义即使有说明界面，也仍是未验证的后置门。
