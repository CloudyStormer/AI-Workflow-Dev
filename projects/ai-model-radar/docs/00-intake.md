# 原始项目需求

## 定位

建立一个与 `ai-english-learning` 同级的实验项目，用来验证 AI 工作流能否交付一个可持续使用的大模型动态聚合工具。

## 超级无敌帅超超总的原始目标

- 可以实时或定时刷新大模型行业动态。
- 每天聚合国内外值得关注的大模型新闻、官方更新、社区讨论和论坛信息。
- 重点覆盖排名靠前或影响较大的模型与厂商，期望每天筛选约 10–20 条。
- 国内可关注哔哩哔哩、微博等公开内容以及厂商官网；国外可关注 X、OpenAI 社区、Codex 社区、论坛、新闻和官网等。
- 减少每天逐个打开收藏站点的重复操作。
- 先由市场调研员研究来源、同类产品和可行边界，再交给项目经理推进。

## 本阶段不做

- 不先决定最终来源清单。
- 不承诺可以抓取需要登录、禁止自动访问或条款不允许的站点。
- 不先写 PRD、界面或采集代码。
- 不把未经验证的排行、热度或摘要当作事实。

## 待调研问题

1. 哪些一手来源足以覆盖主要国内外模型动态？
2. 不同来源的访问方式、更新频率、授权、robots/条款和稳定性如何？
3. 如何定义“前 10–20 条”和重要性，避免只按流量排序？
4. 如何去重、聚类、追溯原文并标注摘要置信度？
5. 实时、小时级和每日摘要的成本与收益分别是什么？
6. 哪些竞品或现有工作流已经解决部分问题？
