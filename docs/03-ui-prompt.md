# 行内字母槽填空：设计提示词与设计任务书

状态：`ready-for-review`  
来源：`06 前端工程师`任务中的 UI/UX + 前端角色入场申请已获超级无敌帅超超总明确同意。  
范围：仅调整单词页的填空模式，不改背单词、聊天、个人中心和其他模块。

## 目标

把答案输入直接整合到英文句子的字母槽中，移除句子下方独立答案输入框。

示例：

- 初始：`_____`
- 输入 `a`：`a____`
- 连续输入：`ap___` → `app__` → `appl_` → `apple`
- 已有随机提示末尾 `le` 时，输入 `a` 后显示：`a__le`

## 用户与场景

- 用户在拼写填空模式中通过键盘或移动端软键盘输入完整答案。
- 用户需要同时辨认自己输入的字母、系统提示字母和仍未填写的槽位。
- 用户可能使用键盘导航、读屏或“减少动态效果”系统设置。

## 核心交互

1. 点击句子中的字母槽区域即可聚焦真实文本输入控件并打开键盘。
2. 连续键入、退格和整词粘贴都直接反映在同一排字母槽中。
3. 系统提示字母固定在原位置；用户仍输入完整答案，由系统合并显示。
4. 输入过程中随机提示图案保持稳定，不因每次按键重排。
5. 按 `Enter` 或点击“检查答案”提交。
6. “检查答案”、反馈信息、继续提示和换组操作保留在卡片内。
7. 页面不再显示句子下方独立的“请输入答案”输入框。

## 视觉与状态

- 空槽：`2px` 底部线，颜色 `rgba(119,108,105,0.42)`。
- 用户输入：`#17131B`，字重 `750`。
- 系统提示：`#4C0C91`，字重 `850`。
- 当前输入位置：紫色下划线和轻微呼吸光标。
- 聚焦：槽位组使用 `rgba(99,33,164,0.12)` 外发光。
- 正确：`#15836F`，并提供文字反馈。
- 错误：`#B54C59`，保留答案供修改；仅播放一次轻微横向反馈。
- 动效：`160–180ms`；开启减少动态效果时取消非必要动画。

必须覆盖：默认、聚焦、输入中、不完整、错误、正确、切题、提示组合不可用等状态。

## 响应式与无障碍

- `<768px`：槽位随句子自然换行或在卡片内部容纳，不产生页面横向滚动；可交互区域高度至少 `44px`。
- `768–1200px`：句子与槽位保持主要阅读关系，操作按钮位于下方。
- `>1200px`：填空卡片居中，字母槽直接嵌入句子。
- 槽位组在辅助技术中表现为一个真实文本输入控件。
- 提供答案长度、已输入数量、提示位置、正确/错误状态的读屏说明。
- 支持 Tab 聚焦、Enter 提交、退格修改与粘贴。
- 不只依赖颜色表达状态。

## 非目标

- 不改变随机字母提示算法的业务规则。
- 不改变其他学习模式和全局设计系统。
- 不在本阶段修改前端代码或生成最终视觉稿。

## 验收标准

- 页面不存在句子下方的独立答案输入框。
- `apple` 输入 `a` 后清楚呈现 `a____`。
- 输入、退格和粘贴都实时映射到字母槽。
- 随机提示、渐进提示和换组继续有效且输入时稳定。
- 正确、错误、下一题流程正常。
- 手机与桌面无页面级横向溢出。
- 键盘、读屏标签和减少动态效果规则可用。
- TypeScript、Lint、构建和浏览器控制台检查通过。

## 审批门

1. 当前只请超级无敌帅超超总审核本提示词。
2. 提示词获批后，UI/UX 角色才能输出设计说明或原型。
3. 设计产物再次获批后，前端角色才能编码。

可回复：`通过提示词`、`需要修改：...` 或 `打回重做`。
