# AI Model Radar

用于验证 AI 工作流的“大模型动态雷达”实验项目。

目标是把国内外大模型的重要动态汇聚到一个界面：定时或按需刷新、跨来源去重、按重要性排序，并给齐总展示每日约 10–20 条值得关注的进展。信息必须回链到原始来源，区分事实、来源观点和系统摘要。

当前只完成项目骨架和调研入场。市场调研、项目计划、PRD、UI 提示词、架构、开发、测试和发布必须按根目录 `skill/ai-dev-workflow/SKILL.md` 的角色审批门逐步推进。

## 预期信息范围

- 国内外模型厂商官方博客、发布页、文档与状态页
- 研究机构论文、基准与技术报告
- 可信开发者社区、论坛和工程讨论
- 行业媒体与高质量分析
- 重大模型发布、能力更新、价格/API/上下文变化、开源、融资并购、监管与安全事件
