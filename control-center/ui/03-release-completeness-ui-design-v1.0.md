## 1. 设计结论

本版把 Control Center 定义为“真实只读监管台”，用 6 个一级导航、12 个 P0 目的页、19 类语义图表和统一证据抽屉完成发布完整性设计。页面不以大段说明替代界面，也不以装饰图表冒充数据：当前事实页只显示“未就绪／覆盖不可用”，成功空态必须有来源证据，目标态数据必须就近标注“目标态演示数据·非当前事实”。

视觉方向采用深靛蓝导航、浅灰底、白卡、克制蓝色信息层级；成功、警告、危险、演示、未知均同时使用中文文字、符号、边框和颜色。所有可操作入口为搜索、筛选、详情、只读重新读取和导出当前查询；批准、问题流转、发布、回滚、修复、删除与 Git 写入均没有可执行入口。

## 2. 真实性与零写边界

- 当前真实监管后端：未实现。
- 工作流读取器：未实现。
- 真实数据接入：未就绪。
- 当前事实：不显示伪造 KPI，不把未知换算为 0，不把静态回退或历史演示称为实时。
- `empty`：仅用于查询成功、来源可用且记录数确实为 0；与 `unknown`、`not_ready` 严格分开。
- `stale`：展示最近快照、源更新时间、本次观测时间和当前失败原因；错误主文案为简中，内部代码只作次级标注。
- `live`：本交付只画目标态演示，不代表当前运行事实。
- 零写：业务写动作和 Git 写动作均为 0；本设计不新增后端、连接器、数据库、服务或部署。

## 4. 全局顶栏与只读交互

每个桌面目的页都包含项目、时间、迭代、来源模式、搜索、只读刷新、导出当前查询、健康、就绪、覆盖、根仓提交、工作树和观测时间。`prototype.html` 提供以下可达交互规范：

- 12 目的页切换，左右方向键移动页面；页签与筛选上下文写入 URL 查询参数，可在重新进入或前进／后退时恢复；路由切换有焦点状态和 `aria-live` 播报结构。
- 项目／时间／迭代／来源筛选和只读搜索均真实参与记录过滤，并改变原型内可见结果集与结果计数。
- 图表标记交叉筛选、清除筛选、问题→复测、发布→六项门禁、状态→来源错误。
- 证据抽屉支持关闭按钮、Escape 和返回触发控件焦点。
- 390/320 自动选用对应移动资产；来源页两端保持同一 `stale` 真相态。
- 只读刷新只播报“读取器尚未接通”；导出形成可见预览，逐项列出当前筛选、来源、来源哈希、错误、生成时间、真实性标签和记录摘要，但不生成真实文件。
- 页级真相在进入过滤前先构造同一份资格记录：当前未就绪与有证据空态不混入目标态／历史／陈旧记录；目标态事件页和“问题→复测”下钻使用同页目标态演示记录；陈旧页只使用静态回退快照。
- 陈旧导出保留当前可见行的“来源解析失败（SOURCE_PARSE_FAILED）／连接器未接通（CONNECTOR_NOT_READY）”；审批成功空态只允许已取证的锁定范围，明确展示来源 ID、来源状态、观测时间和由规范化来源内容计算的 64 位来源 SHA256，并另行计算查询范围 SHA256，二者不得互相冒充。
- 陈旧页执行“清除筛选”后恢复该页默认静态回退来源，不会误切正式来源并清空快照。

当前原型源码已将点击、方向键、`aria-current`、URL、H1 和 dataMode 全部统一到 `button.dataset.index`，并在 390/320 落实“总览／项目／质量／更多”底栏及覆盖 12 页的更多菜单；页面 2–6 映射“项目”、页面 7 映射“质量”、页面 8–11 映射“更多”，底栏当前态与更多菜单内精确页当前态分开表达。审批空态在页面激活时同步锁定筛选／搜索并禁用伪标记；页级图表标记按项目、角色、产物、事件、问题、发布、治理等当前对象上下文切换；“产物与哈希”页只读取同真相态目标演示产物，历史视觉母版保留但不混入目标态查询。浏览历史使用 `pushState / replaceState / popstate`。当前浏览器 checker 已扩展为 11 组，新增产物页同真相对象／历史隔离与 12 页移动底栏当前态断言；fixed00 已在 `http://127.0.0.1:48175/prototype.html` 对当前图例修复候选原样执行，结果为 `exit 0 · 11/11 passed · console 0 errors / 0 warnings`，并绑定精确 prototype、generator 与 checker SHA。329d 与 8c6 的结果仅作历史。该浏览器结论不等于独立视觉通过；屏幕阅读器实际话语、生产字体和真实服务行为仍为独立审查／实现验收项。

## 6. 设计系统、响应式与无障碍

- 设计系统页：颜色与 4.5:1 小字对比目标、排版、8px 栅格、状态组件、按钮、输入框、Toast、加载态、表格、抽屉、focus-visible、hover／pressed／disabled／error 和 motion token。
- 动效：标准 160ms 缓出；减少动态效果时为 0ms、无位移，状态变化保留文字与播报。
- 桌面／平板语义文字：所有用户可见 SVG 业务文字最低 12px；验证器逐个 `<text>` 解析并以 11px 负夹具证明门禁会失败。
- 移动端：正文按 16px 编写，辅助文字最低 14px，触控目标最低 44×44；每个 320 关键页就近呈现零写边界。移动成熟度组合显式展示角色职责、阶段审批、产物追溯、自动执行、测试评测、可观测成本六维，以及规则、样本和缺失项。
- 200%：720 物理像素对应 360 CSS 有效视口；字体、间距、圆角、描边与卡片余量按 2×物理尺寸回流，覆盖导航、筛选、图例、图表／等价表、数据表／卡片、证据抽屉和操作区，无页面级横向滚动。
- 非颜色单一表达：所有状态都有简中标签、符号、边框和颜色；内部状态键仅保留在 manifest 或次级代码标注中。
- 静态 SVG/PNG 不等于键盘或读屏验证；机器门只验证可访问名称、ID 解析、静态结构和文字规则。
